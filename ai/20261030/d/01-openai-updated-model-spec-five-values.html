更新 Model Spec：围绕「忠于人类意图」等五项价值重组行为规范

OpenAI 于 10 月 29 日更新公开的 Model Spec，把模型行为指引按五项底层价值重组：忠于人类意图、尽量减少伤害、诚实透明、促进人的主导权，以及关怀；并称现网模型尚未完全体现新规范。

2026-10-30 OpenAI

OpenAI 官方博客写明：随着模型更强、会在现实中采取更有后果的行动，只「字面执行指令」不够，还需要理解人的意图与价值，在说明书没写死的情境里做出稳妥判断，同时服从人的主导。更新后的 Model Spec 把原有散落指引收拢到五项价值之下，并补充关于上下文、监督与主导权的表述，调整一部分默认行为，同时大幅删减细碎的风格规定。

五项价值里，公司把「忠于人类意图」放在基础位置：不只机械跟指令，还要尽量搞清 OpenAI、开发者与用户各自看重什么，在信息不全时谨慎行事；也承认人的偏好会变，帮助对方反思时不要悄悄带节奏或替人做主。其余四项分别对应安全边界与可预见后果、对所知与不知如实说明、增强人自己理解与选择的能力，以及对受影响者处境与行业规范的照顾。规范里该硬的边界写死，其余多半是可被用户与开发者改写的默认。

结构上，新版本写入「指令优先级链」、要求认真考虑对话记忆与上下文，并新增支持人主导、遵循相关社会规范、控制与说明副作用等默认。公司同时弱化「把模型叫作助手」的写法，改称 GPT，并表示风格应随语言文化与个人偏好适应，而不是 Spec 里塞满细则。Reuters 等通稿转述同一五点框架，强调这是对齐工作的一部分，现网模型「尚未完全反映」更新后的 Spec，训练方法仍在探索。
