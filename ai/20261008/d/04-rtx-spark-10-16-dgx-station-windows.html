英伟达 / NVIDIA

RTX Spark 电脑开启预订、10/16 发货，DGX Station 首次推出 Windows 版

在微软 10 月 7 日的旧金山发布会上，英伟达宣布 RTX Spark 笔记本当天开启预订、10 月 16 日发货，同时预览首款 Windows 版 DGX Station，把 GB300 级算力搬到企业桌面。

2026-10-08 英伟达 / NVIDIA

这场 Windows AI 与 Surface 发布会在旧金山 Dogpatch Studios 举行，前白宫 AI 政策顾问斯里拉姆·克里希南主持了黄仁勋与纳德拉的对谈。黄仁勋回顾说，英伟达因 Windows 而起，「没有 Windows 就没有 GeForce」；现在智能体要进入个人电脑，电脑会变成真正的个人助理。纳德拉则强调，要让桌面成为智能体最安全的运行环境。

硬件方面，RTX Spark 是英伟达为 Windows 电脑做的超级芯片：最多 6144 个核心的 Blackwell RTX GPU，加最多 20 核的 Grace CPU，两者以 600GB/s 互连，FP4 算力约 1 PFLOPS，统一内存最高 128GB。宏碁、华硕、戴尔、惠普、联想、微软、微星、技嘉八家厂商推出产品，笔记本当天可预订、10 月 16 日起供货，小型台式机 11 月开卖。英伟达称它能不联网、不计量地在本地跑约 1250 亿参数的模型，游戏方面可在 1440p 下借 DLSS 5 跑到 100 帧以上。

更受企业关注的是 DGX Station for Windows。此前 DGX Station 只跑 Linux，企业开发者得同时维护两套环境；新版本基于 GB300 Grace Blackwell Ultra 桌面超级芯片，配 748GB 一致性内存、最高 20 PFLOPS 的 FP4 算力，英伟达称足以在本地运行万亿参数级模型，Linux 工具链可通过 WSL 使用。不过英伟达只给出预览，没有公布价格和上市时间，只开放了到货提醒登记。英伟达特别提到，《财富》500 强大多以 Windows 为标准桌面，这是它把旗舰工作站搬到 Windows 的理由。

软件层面，英伟达把自家智能体安全组件 OpenShell 接入了微软同日正式推出的 Execution Containers，为文件访问、推理服务和网络提供额外的策略控制；黄仁勋称，MXC 对智能体的意义好比当年 DirectX 对 Windows 应用。微软 Windows 负责人达武卢里则称，有了 MXC、微软安全产品和 Agent 365，智能体在 Windows 上才能被保护、观察和管理。

这次发布标志着英伟达正式以 CPU＋GPU 一体芯片进入 Windows 笔记本市场，与苹果 M 系列和高通骁龙 X 直接竞争。真正的考验在后面：Windows on Arm 的软件兼容性、续航，以及高端定价能否被市场接受。

  • 待确认：DGX Station for Windows 的价格与上市日期未公布；1 PFLOPS 为厂商标称的 FP4 峰值。
