Windows Search 换上 WinUI 3：预览版可在搜索框里直接改深色模式、蓝牙和窗口布局

微软 10 月 7 日起向 Windows Insider 实验通道推送新版任务栏搜索：基于 WinUI 3，结果改成单列，并加入「行内操作」，可直接开关深色模式、夜间模式、蓝牙，或调整亮度、静音、最小化与并排窗口。首发仅英文。

2026-10-08 操作系统与桌面

微软在 Insider 博客写道，新的 Windows Search 体验从 10 月 7 日起在实验通道任务栏上逐步放开。它改用 WinUI 3，官方称早期测试里性能和内存占用都有明显改善；界面收成单一结果列表，去掉大部分右侧大预览，理由是数据显示用户几乎都点左侧列表。

更大的变化是「行内操作」（inline actions）：搜索不再只负责「找到」，还可以在当前位置把事做完。官方举例包括「切换到深色模式」「打开夜间模式」「打开蓝牙」「把屏幕调暗」「静音」「最小化全部窗口」「并排排列窗口」。后续还预告了与 Phone Link 相关的手机操作，以及年内加入的行内文件预览、更丰富的网页预览和分类筛选。

试用条件较窄：需升到实验通道 build 26340.9616 或实验（26H1）通道 28120.3181，再检查更新并重启，必要时在「功能开关」里打开「新 Windows Search 体验」；首发语言为英文。开始菜单里的搜索暂时仍是旧界面。The Verge 等媒体把这一波与前一日发布会的「混合智能」叙事放在一起理解，但强调 Copilot 更深整合仍属后续计划、且将以可选方式出现。

需要与晨报区分：微软 Execution Containers（系统级智能体容器）已在晨报单独成卡。本卡只覆盖搜索壳层与行内操作，不重复容器与 RTX Spark 硬件新闻。

交叉核对

  • 官方：Windows Insider 博客 10/7 详述 WinUI 3、单列 UI、行内操作与 Insider 开启步骤。
  • 次要：The Verge 等将搜索改造放在 10/7 Windows 发布会同日叙事中，并指出 Copilot 整合仍为后续、可选。
  • 范围：仅实验通道预览，不是向所有 Windows 11 稳定版用户推送。
