Node.js 26.11.0：新增整进程超时看门狗，SQLite 类名去掉 Sync 后缀

Node.js 10 月 7 日发布 26.11.0（Current 线），最实用的新功能是整进程超时看门狗 --process-timeout，另外 SQLite 模块的两个核心类改了名，旧名暂时保留。

2026-10-08 语言 / 运行时 / 框架

这一版由发布负责人安托万·杜阿梅尔签发，属于 Current 发布线的常规小版本，但新增功能不少。最受关注的是 James M Snell 提交的 --process-timeout=N：给整个 Node 进程设定运行时限，超时后打印当前卡住位置的诊断信息并以退出码 124 结束。这和 Unix 的 timeout 命令习惯一致，适合 CI 任务、定时脚本这类「跑飞了就该停」的场景，过去要靠外部工具或自己写定时器。

Buffer 模块新增两个函数：Matteo Collina 提交的 Buffer.stringLength() 可以直接算出字符串编码后的字节长度，isLatin1 用来判断数据是否全为 Latin-1 字符。http 模块公开了 isValidHeaderName() 和 isValidHeaderValue()，框架作者不必再复制内部的请求头校验逻辑。http2 增加 connectionWindowSize 选项，用于调整连接级流量控制窗口。

SQLite 方面，内置 node:sqlite 模块的 DatabaseSync 和 StatementSync 分别改名为 Database 和 Statement，旧名作为别名保留，现有代码不会立刻出错。这为将来加入异步接口理顺了命名，同时新增了通过 createModule() 实现虚拟表的能力。另外，process.ref／unref 从实验转为稳定，perf_hooks 的直方图新增 diff() 和 snapshot()，便于做前后对比的性能监测。

平台和依赖方面，Alpine Linux 从实验级提升为二级支持，对大量用 Alpine 做容器基础镜像的团队是好消息。随附组件升级到 OpenSSL 3.5.9、npm 11.20.0、undici 8.11.2，时区数据更新到 2026e，根证书更新到 NSS 3.129。此外还有一批稳定性修复，例如 ffi 模块的释放后使用问题、fs 递归建目录可能无限重试的问题。

需要提醒的是，26.x 目前仍是 Current 线，生产环境多数仍跑 LTS 版本；这些新接口要等进入 LTS 或被移植后才会被广泛使用。
