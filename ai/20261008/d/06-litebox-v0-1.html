开源治理与许可证

微软开源沙箱库操作系统 LiteBox 放出首个标记版 v0.1

微软 10 月 7 日在 GitHub 为 LiteBox 打上 v0.1 标签。这是一套用 Rust 写的 Library OS，通过缩小应用与宿主之间的接口来降攻击面，可在 Linux/Windows 等环境做沙箱，仍处活跃开发，API 可能变动。

2026-10-08 开源治理与许可证

Phoronix 与 IT之家报道，微软安全向的开源项目 LiteBox 于 10 月 7 日放出首个 git 标记版本 v0.1。项目定位是 Library OS（库操作系统）：不像完整虚拟机那样带一整套内核，也不像普通容器那样直接共享宿主内核，而是只向底层暴露尽量小的接口集合，用 Rust 与 Linux 虚拟化安全能力把应用关进更窄的沙箱。

公开材料里的典型场景包括：在 Linux 上沙箱化 Linux 应用、在 Windows 上跑未修改的 Linux 程序、以及在 AMD SEV-SNP、OP-TEE、微软 Linux 虚拟化安全等机密计算环境中运行负载。架构上区分「北向」POSIX 风格接口与「南向」宿主连接，并可在内核态或用户态运行。Windows 运行器目前仅支持 x86-64。

v0.1 的发布说明很短，微软表示以后版本会给更详细的变更日志，并提醒 API 仍可能变化，不适合把稳定性要求很高的生产系统直接押在当前接口上。IT之家指出，目前还看不到与 gVisor、Firecracker 的公开性能对比，也未说明 LiteBox 是否会进入 Azure 或 WSL 产品线。

放在本栏是因为这是微软把沙箱运行时以 MIT 许可开源、并完成「从早先公开代码到首个版本标签」这一治理节点；与晨报已写的 Windows Execution Containers（产品级智能体容器 GA）是不同层面——一个是开源 Library OS 实验，一个是 Windows 11 上的策略化容器产品。

交叉核对

  • 多方一致：Phoronix（10/7）、IT之家（10/8）均确认 v0.1 为首个标记版，且仍在活跃开发。
  • 项目页：GitHub microsoft/litebox 描述为面向安全的 Library OS。
  • 待确认：性能数据、产品化路线（是否进入 Azure/WSL）官方均未表态。
