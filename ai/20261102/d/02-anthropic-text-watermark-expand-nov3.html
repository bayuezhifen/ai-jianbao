Claude / Anthropic

Claude 文本水印扩至 Mythos 5、Opus 4.7/4.6、Sonnet 4.6，11 月 3 日起生效

与 Opus 5.5 同款的不可感知文本水印，将自 2026-11-03 起覆盖 Mythos 5、Opus 4.7/4.6、Sonnet 4.6；Bedrock 部署或再晚数日。检测 API 仍为受限预览。

2026-11-02 Claude / Anthropic

Anthropic 正把已在 Claude Opus 5.5 上线的不可感知文本水印，扩展到更多仍在服务的旧版型号。Mashable 东南亚站等媒体报道称，自 2026 年 11 月 3 日起，Mythos 5、Opus 4.7、Opus 4.6 与 Sonnet 4.6 的默认文本输出将带上同款水印；公司新闻稿与支持文档同步说明，此举与欧盟《AI 法案》对生成内容透明度义务的对接有关。

按官方口径，水印对终端用户「不可感知」——不改变可见文案，而是在统计层面留下可供检测器识别的痕迹。Anthropic 提供的检测接口目前仍处于受限预览，并非面向所有开发者开放的通用查重 API。Amazon Bedrock 上的对应型号，报道称可能比直连 Claude 再晚数日才完成同一开关。

扩展名单刻意覆盖「仍被大量调用的旧代」，说明公司不愿只在最新旗舰上做合规示范，而要把存量流量一并纳入可声明的生成标记体系。支持页「How Claude marks AI-generated content」把水印定位为多信号方案的一部分，而不是唯一防伪手段。

需要谨慎看待的一点是：社区与安全研究者此前指出，在 Opus 4.6 / Sonnet 4.6 上若大幅改动采样参数，检测器可能出现漏检（所谓 Decoder loophole）。官方尚未把「任意参数下绝对可检出」写成硬保证。对企业合规团队而言，宜把 11 月 3 日开关当作默认路径变更，同时保留日志、内容策略与人工抽检，而不是把水印检测当成唯一证据链。

交叉核对

  • 多方一致：11-03 起扩至 Mythos 5、Opus 4.7/4.6、Sonnet 4.6；与 Opus 5.5 同款不可感知水印；对接欧盟 AI 法案透明度；检测 API 仍为受限预览。
  • 分歧：Mashable 等强调覆盖时间表与 Bedrock 可能滞后；Anthropic 官方页更偏机制与合规动机说明。
  • 待确认：Bedrock 精确上线日、Decoder loophole 在扩覆盖后是否仍可复现、检测 API 何时转正式商用，以官方后续通告为准。
