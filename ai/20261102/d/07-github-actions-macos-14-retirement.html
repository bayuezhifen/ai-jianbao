GitHub Actions 正式退役 macOS 14 运行镜像

按计划于 2026-11-02 退役 macos-14 / macos-14-large / macos-14-xlarge；工作流若仍指定这些标签将失败，需改用 macos-15、macos-latest（macos-26）及对应 large/xlarge。

2026-11-02 开发者工具

GitHub Actions 的 macOS 14（Sonoma）托管镜像按计划于 2026 年 11 月 2 日正式退役。官方 Changelog 与 runner-images 议题写明：标签 macos-14、macos-14-large、macos-14-xlarge 即日起不可再用于新的作业排队；继续写这些 runs-on 值的工作流会直接失败。这是预告到期，不是临时故障。

迁移目标是 macos-15 以及 macos-latest（当前指向 macos-26）和各自的 large / xlarge 规格。早在 10 月 1 日的预告帖里，GitHub 已给出时间表与替换对照；议题 #13518 跟踪社区反馈与边缘案例（例如仍钉死在 14 的第三方 Action）。组织内部若有封装层——可复用 workflow 或自建 runner 标签别名——需要同步改别名，避免「仓库 YAML 已改、封装层仍指向 macos-14」的二次故障。

对 iOS/macOS CI 来说，镜像大版本跳跃往往伴随 Xcode 默认版本、SDK 与模拟器列表变化。除了改 YAML 标签，还应在暂存分支跑一遍签名、测试与归档任务，确认证书与依赖缓存键仍然命中。缓存键若硬编码了旧镜像名，也会在迁移后出现「看似跑通、实则用了过期工具链」的隐性问题。

本条是日历到期型变更：没有可拖延的灰度，错过即红灯。建议在组织文档里把 macos-14 从推荐矩阵删除，并在失败日志里准备好「标签已退役」的说明，减少值班误判为 GitHub 全局故障。

交叉核对

  • 多方一致：2026-11-02 退役 macos-14 / large / xlarge；需改用 macos-15、macos-latest（macos-26）及对应 large/xlarge；官方 Changelog 10-01 已预告。
  • 分歧：Changelog 给官方时间表与标签对照；runner-images 议题承载迁移问答与个案。
  • 待确认：个别第三方 Action 钉死 macos-14 的修复进度，以各 Action 仓库为准。
