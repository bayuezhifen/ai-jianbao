xAI 文档：Grok API 文本水印 11 月 7 日起默认开启

SpaceXSI/xAI 开发者文档写明，自 2026-11-07 起 grok-4.7 及所列 4.x/4.20 型号 API 文本输出默认含水印，响应可带 x-watermark 头；团队管理员可按模型选择退出，以对接欧盟 AI 法案透明度义务。

2026-11-03 Grok / xAI

xAI（文档品牌亦写作 SpaceXSI）在开发者文档「Output Watermarking」中明确：自 2026 年 11 月 7 日起，所列文本生成模型的 API 输出将默认带上不可见水印。覆盖型号包括 grok-4.7、grok-4.6、grok-4.5、grok-4.3，以及 grok-4.20-reasoning、grok-4.20-non-reasoning、grok-4.20-multi-agent。适用范围含全球与区域端点，以及 Responses API 与 Chat Completions API；普通文本、结构化输出与工具调用参数中的生成文本均在列。

机制上，水印在生成时微调 token 选择，不额外插入字符或隐藏标记，官方称不影响回复长度、质量与速度。调用方无需改请求参数；可通过响应头 x-watermark 判断当次是否加水印（值为 true 表示已加水印）。检测侧为统计判定，较长文本信号更强；检测 API 需另行申请。

退出权放在团队管理员：控制台可按模型开关，变更约五分钟内对新请求生效，并写入审计日志。选择退出需确认适用法律下的例外，并由使用方自行承担标记或披露义务；部分型号可能对团队锁定为开启。CryptoBriefing、Neural Brew 等二次报道指出，此举对接欧盟 AI 法案透明度要求，且主要针对 API/企业接入，消费端产品不在本轮说明范围内。

对开发者而言，这是合规与对接方式的变更预告，而不是新模型发布。读文档时宜关注默认开启日、型号清单与控制台退出流程；是否影响下游内容审核、版权争议取证，仍取决于检测接口开放范围与各国执法实践。本文不讨论版本排期例行核验。

交叉核对

  • 分歧：CryptoBriefing 等更强调「北美仅 ChatGPT 尚未文本水印」的行业对照；官方文档聚焦接口行为与退出流程。
