ChatGPT Enterprise 上架 AWS Marketplace

OpenAI 周一宣布，企业版 ChatGPT 可以通过亚马逊云科技市场购买和结算，符合条件的开支还能计入客户已有的云承诺消费。功能与直销版本同步，定价走非公开的专属报价。

2026-11-09 OpenAI

OpenAI 在 11 月 9 日的新闻稿里宣布，ChatGPT Enterprise 即日起可在 AWS Marketplace 上架。公司的说法是：企业可以沿用已经和亚马逊云科技建立的采购、开票关系来发现、购买和管理这套办公产品，并且把符合条件的开支计入已承诺的云消费。新闻稿强调，经由市场买到的版本与直接向 OpenAI 购买的是同一套模型、功能和更新节奏，不会单独落后一截。

上架的并不是一个孤立的聊天窗口。官方点和 Marketplace 页面把 ChatGPT、ChatGPT Work、Codex 以及名为 dots 的常驻智能体打成同一份企业套餐：日常对话、能跨多步做研究和出文档的 Work、写代码的 Codex，再加上会在对话之间继续盯项目的 dots。符合条件的客户还可以通过同一渠道购买面向医疗和金融服务的专门版本，具体资格要由 OpenAI 或 AWS 的客户经理确认。OpenAI 云计算合作董事总经理 Chris Grusz 把这件事写成减少企业同时对接两家供应商时的摩擦；Sophos 首席技术官 John Peterson 则说，走单一渠道并动用已有云承诺，能少花时间在采购流程上。

PPC Land 核对了 Marketplace 页面后补充了几个官网新闻稿没写细的地方。这份商品按软件即服务交付，由 OpenAI 销售、AWS 开票，页面上没有公开目录价，买家必须申请专属报价。符合条件的消费可以计入企业折扣计划或私下定价协议里的承诺额，但页面用了“以客户与 AWS 的协议为准”这样的限定。Claude Enterprise 已经在同一货架上，同样写明开支可以抵扣云承诺——也就是说，OpenAI 这次是补上竞争对手已经在用的采购通道，而不是发明一种新的计费方式。

数据与分工上，OpenAI 把这次上架写成和 Amazon Bedrock 里的 OpenAI 模型互补：开发者继续在 Bedrock 上调用模型去搭应用，业务团队则用 ChatGPT Enterprise 做日常工作。PPC Land 还读到，Listing 把 OpenAI 写成数据处理者，并把 AWS 列为分包处理方，同时声明企业数据默认不用于训练模型。页面没有说明走 AWS 账单的客户，数据是否全部留在亚马逊云上，也没有公布适用的国家和地区。微软与 OpenAI 过去一年对云合作条款的修订，已经允许非应用程序接口类产品在不同云上提供；今天这篇新闻只拿“和直销同步”作比较，没有谈相对于 Azure 的上架先后。

对采购部门来说，这条消息的实质是把企业版 ChatGPT 从一份单独的软件合同，挪到许多公司本来就要消化的云承诺额度里。它不改变模型本身，却可能改变预算从哪一笔钱出、谁有权拍板。目前仍缺公开单价、AWS 抽成比例，以及医疗、金融两个行业版本的具体准入条件，这些都还要看后续的专属报价。

交叉核对

  • 多方一致：OpenAI 官网与 PPC Land 均确认 11 月 9 日 ChatGPT Enterprise 上架 AWS Marketplace，功能与直销同步，符合条件的开支可计入 AWS 承诺消费。
  • 官网新闻稿列出套餐内的 ChatGPT、ChatGPT Work、Codex 和 dots，以及医疗、金融两个行业版本；PPC Land 核对其 Marketplace 页面，补充了专属报价、无公开目录价、以及 Claude Enterprise 已在同一货架上。
  • 引述差异：我们打开的官网新闻稿引用了 OpenAI 的 Chris Grusz 和 Sophos 的 John Peterson；PPC Land 则主要引用 AWS Marketplace 副总裁 Matt Yanchyshyn。两边并不互相否定，更像各自摘了不同的表态。
  • 待确认：单价、AWS 平台费、数据是否全部在 AWS 区域处理、以及行业版本的资格标准，官方材料均未公布。
