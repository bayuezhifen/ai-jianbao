xAI：Grok API 文本水印自 11 月 7 日起默认开启

xAI 文档：自 2026 年 11 月 7 日起，所列 grok-4.7/4.6/4.5/4.3 与 grok-4.20 等变体默认加水印；响应头 x-watermark；团队管理员可按模型退出；面向欧盟 AI 法案合规。

2026-11-05 Grok / xAI

xAI 开发者文档「Output Watermarking」写明：受支持的 Grok 文本模型输出含不可见水印，便于事后识别是否由模型生成；请求侧无需改参数，集成方式不变。文档称此举为符合欧盟 AI 法案（EU AI Act），并在包括 https://api.x.ai 在内的全球与区域端点生效。

自 2026 年 11 月 7 日起，下列模型默认开启水印：grok-4.7、grok-4.6、grok-4.5、grok-4.3，以及 grok-4.20-reasoning、grok-4.20-non-reasoning、grok-4.20-multi-agent。覆盖 Responses API 与 Chat Completions API 的生成文本，含结构化输出与工具调用参数。可用响应头 x-watermark: true 判断该次是否加水印。

水印在生成时微调 token 选择，不额外插入字符或隐藏标记；检测为统计式，文本越长信号越强。检测 API 需另行申请。团队管理员可在控制台按模型退出；变更约五分钟内对新请求生效，退出需确认适用法律例外并自行承担标记义务。部分模型可能对团队锁定无法关闭；操作写入审计日志。文档称水印不影响质量与速度。

本条只报道文档中的默认开启与退订机制，不延伸讨论版本路线图或训练进度。
