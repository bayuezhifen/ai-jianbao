OpenAI 将收购 Pierre，强化 Codex 源码工作流

OpenAI 11 月 4 日宣布将收购 Pierre Computer：Code Storage 与已嵌入 Codex 的 Trees/Diffs 等开源工具；开源项目继续开源；交割需监管批准，此前双方保持独立。

2026-11-05 OpenAI

OpenAI 于 2026 年 11 月 4 日发文宣布将收购 Pierre Computer Company, Inc.（Pierre）。公告写明：若你在 Codex 应用里浏览文件或审阅变更，其实已经在用 Pierre 的 Trees 与 Diffs 库。公司希望把围绕 Git 的工作流继续适配「编码智能体」并行协作的方式，并与本周介绍的内部源码后端 Pando 形成互补。

官方强调：Pierre 的开源项目将保持开源并继续贡献；交割完成后客户仍可使用 Code Storage，同时团队会把相关能力逐步纳入 Codex。收购交割须满足惯例交割条件（含监管批准）；在交割完成前，OpenAI 与 Pierre 仍是独立公司。金额未披露。

Axios 独家报道把这笔交易放在「挑战微软 GitHub」的叙事里：GitHub 面向人类协作设计，而越来越多代码由 AI 写出，OpenAI、Cursor 的 Origin、前 GitHub CEO 新公司等均在探索 AI 优先的源码基础设施。OpenAI 称 Pando 将推送变更所需时间缩短近八成，并在考虑对客户开放。读法上，官方主条是「强化 Codex 审阅与存储」；「替代 GitHub」是媒体外延，不宜写成已承诺的产品路线图。

对开发者：交割前 Codex 内嵌的 Trees/Diffs 体验与 Pierre 独立产品仍分属两套主体；开源许可承诺以 OpenAI 公告为准。监管进展与整合时间表待后续披露。

交叉核对

  • 多方一致：OpenAI 11-04 官方宣布收购 Pierre；Trees/Diffs 已在 Codex；开源继续开源；交割需监管；交割前保持独立；金额未披露。
  • 分歧：Axios 强调挑战 GitHub / 与 Pando 联动；官方措辞更偏 Codex 工作流与 Code Storage 整合。
  • 待确认：对价、监管时间表、Code Storage 并入 Codex 的具体形态。
