Go encoding/json/v2 与 jsontext 在 Go 1.27 稳定可用

Go 官方博客：经过实验与反馈，encoding/json/v2 与 encoding/json/jsontext 在 Go 1.27 中稳定可用，修复 UTF-8/重复键等行为问题并改善流式与 Unmarshal 性能。

2026-11-05 语言 / 运行时 / 框架

Go 团队于 2026 年 11 月 4 日发文宣布：新的 encoding/json/v2 与 encoding/json/jsontext 包已在 Go 1.27 中稳定、可一般使用。文章回顾了 v1 在非法 UTF-8 默许、对象重复键、nil 切片/映射序列化为 null、大小写不敏感匹配等行为争议，以及 MarshalJSON/UnmarshalJSON 接口带来的分配与性能瓶颈。

架构上，jsontext 负责语法层流式编解码（真正面向 io.Reader/Writer 的 Token/Value），v2 负责语义层的 Marshal/Unmarshal，并新增 MarshalJSONTo/UnmarshalJSONFrom 等流式接口。默认行为更严格：拒绝非法 UTF-8 与重复成员名；nil 切片/映射默认编成空数组/对象；结构体字段名默认大小写敏感匹配。多数行为差异可用选项或标签切回 v1 语义。

兼容性方面，v1 将长期保留；实现上 v1 可借由选项集建立在 v2 之上，使两边自定义方法可互通，降低生态迁移摩擦。基准上 Unmarshal 最高可有数量级改善，Marshal 与 v1 大致持平。团队提供迁移指南与「Working with JSON」教程。

对库作者：新代码可优先考虑 v2；依赖旧默认的应用应先对照行为差异表再切换，尤其是重复键与 UTF-8 校验会改变「曾经能解」的输入是否报错。
