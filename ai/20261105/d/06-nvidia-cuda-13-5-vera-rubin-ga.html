CUDA 13.5：Vera Rubin 生产可用，MPS v3 与 CUDA Tile 增强

英伟达 11 月 4 日开发者博客：CUDA Toolkit 13.5 为 Vera Rubin 提供生产级（GA）支持；DGX Station Windows on Arm；MPS v3 加权分时；CUDA Tile 多 GPU 与 SIMT 互操作预览。

2026-11-05 英伟达 / NVIDIA

英伟达开发者博客 2026 年 11 月 4 日宣布 CUDA Toolkit 13.5 正式可用。核心变化是 NVIDIA Vera Rubin GPU 架构支持从早期开发者访问升至一般可用（GA），可按生产环境部署。自 13.4 起已 GA 的 Windows on Arm 支持，此次延伸到 NVIDIA DGX Station for Windows。

资源调度方面，locality domain 允许在「各域均匀 SM 分区」与「尽量吃满补充 SM」之间选择，并通过 cudaDevSmResourceSplit() 发现分区 SM 数。Multi-Process Service（MPS）v3 新增加权分时、SM 分区借用/出借负载均衡、基于 cgroup 的路由、按命名空间的 SM 分区分配，以及内存记账的轮询回退。CUDA Tile 增加经 NVLink/NVSwitch 的单播与组播指针多 GPU 通信，并公开预览 Tile 内核直接调用 NVSHMEM、CCCL Coop、Warp、MathDx 等 SIMT 库设备函数。

同版还包括 CUDA Python cuda.core 1.2（批量拷贝、PDL、更灵活的 Graph 更新）、CCCL 3.5（CUB 调参 API、可复现浮点扫描、批量 Top-K 等）、Nsight 工具与数学库在 Vera Rubin 上的性能改进。Rubin 起 Windows 支持 WDDM/MCDM，不再支持 TCC 模式。

对运维与平台团队：若现网脚本假设 TCC，需按目标系统改到 WDDM 或 MCDM。Tile–SIMT 互操作仍是预览，C++ 需 nvcc --tile-preview simt。完整平台矩阵以 13.5 发行说明为准。
