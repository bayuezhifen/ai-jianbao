OpenAI 推出 Images 2.6：约快50%，支持 GIF，API 分 Flare/Sunburst

Images 2.6 已登陆 ChatGPT、Codex 与 API：生成约快 50%，支持 GIF；API 提供 GPT-Image-2.6 Flare（偏速度）与 Sunburst（偏细节与编辑一致性），全球各档订阅可用。

2026-11-05 OpenAI

OpenAI 于 2026 年 11 月 4 日发布 Images 2.6，覆盖 ChatGPT、Codex 与 API。官方称图像生成较此前约快 50%，并可用 GIF 把品牌吉祥物、产品静图等做成循环动效。公司同时给出用量背景：ChatGPT、Codex 与 API 合计每周约生成 40 亿张图像。

在 API 侧，开发者可选用 GPT-Image-2.6 Flare 与 GPT-Image-2.6 Sunburst。质量设为 low 时，Flare 最快可在约六秒内出图，并改善海报、产品图等版式；需要更高细节与跨轮编辑一致性时，可选用 Sunburst（medium/high）。API 还引入图像标注（此前已在 ChatGPT）、SVG 导出，以及控制「规划深度」的 complexity 参数。

Images 2.6 已在桌面、移动与网页端向全球各订阅档位开放；Flare/Sunburst 的计费见定价页，安全评估见系统卡。对产品团队：若工作流依赖多轮角色/品牌一致性，宜对照官方建议在低 complexity 快改与高 complexity 复杂场景之间取舍；GIF 能力面向营销与原型，不等于视频生成。

本条仅依据 OpenAI 官方博文，不外推未写明的模型底座名称或区域差异。
