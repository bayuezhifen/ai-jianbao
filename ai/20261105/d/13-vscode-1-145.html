Visual Studio Code 1.145：Agents 预览与本地 cron 自动化等

VS Code 1.145（2026-11-04 稳定版）：远程智能体会话可预览应用与画布；本地自动化支持 cron 与工作区自定义智能体；聊天详细程度可选等。

2026-11-05 开发者工具

微软于 2026 年 11 月 4 日发布 Visual Studio Code 1.145 稳定版。发布说明把重点放在智能体工作流：远程智能体主机上的会话可在 Agents 窗口内通过集成浏览器预览应用（设置 workbench.browser.enableRemoteProxy），并支持远程托管的画布（需同时打开画布相关设置）。

本地自动化新增 Cron：可在内置预设之外填写五段 cron 表达式，对话框会校验并描述调度结果（云端自动化不可用 cron）；还可选用工作区自定义智能体。嵌套会话预览允许子会话选用与父会话不同的 harness（如 Claude / Codex / Copilot 并列）。聊天侧可在 Conversation / Verbose / Compact 等视图模式间切换，控制推理与工具调用的展开程度。

其他还包括：排除文件夹时用 ! 例外显示特定路径；企业侧必装插件不可卸载、托管 MCP 允许列表优先于「仅注册表」；弃用 Local harness 的部分工作区创建/装扩展工具。趣味彩蛋：Blobby 跳跃小游戏。

本栏只收 VS Code 官方更新，不与 Cursor 空窗混淆。生产组织请先核对企业策略与预览开关再全量推送。
