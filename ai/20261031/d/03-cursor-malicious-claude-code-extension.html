Cursor 扩展市场出现恶意 Claude Code 版本，试图植入 SSH 后门

Cursor 披露：10 月 29 日约太平洋时间 2:27–13:35，扩展市场短暂出现非 Anthropic 出品的 Anthropic.claude-code 2.1.312 / 2.1.313（Windows / macOS），恶意逻辑会收集主机信息、写入 SSH 公钥并试图建立反向隧道；10 月 30 日公司再次更新 IoC。

2026-10-31 Cursor

官方安全通告写明：涉事版本并非 Anthropic 开发，仅影响从 Cursor VS Code 扩展市场安装的上述两个版本；其他 marketplace 扩展、Grok Bot 等产品不在此事件范围内。恶意代码会采集主机名、用户、系统架构、家目录、环境变量名、工作目录、Git 邮箱与公网 IP，并向攻击者上报；随后尝试把攻击者 SSH 公钥写入 authorized_keys、拉起本机 SSH 服务并建立反向隧道，再通过 LaunchAgent（macOS）或计划任务 / 启动脚本（Windows）做持久化。

Cursor 强调：在绝大多数未以管理员权限启动 Cursor 的机器上，开启本机 SSH 服务这一步会因权限与恶意代码自身错误而失败，攻击者未必能真正登录；但公钥写入、持久化脚本与主机信息外传仍可能已经发生。攻击者服务器已被云厂商配合下线。公司下架恶意包、短暂关闭市场审计后重建上线，并轮换密钥。Sophos X-Ops 转述称受影响用户量级估约五千，并提醒「只卸扩展不够」，必须清公钥、清持久化与隧道进程，再轮换凭据。

10 月 30 日太平洋时间约 11:30，Cursor 更新了 IoC 并澄清受影响版本。若你在曝光窗口内安装或更新过 2.1.312 / 2.1.313，应按官方脚本检查 `svc-telemetry` 公钥痕迹，必要时执行 remediation 脚本并隔离主机。本简报只摘要事件与处置要点，不复述利用步骤或完整 payload。

窗口说明：首发通告在 10 月 29 日，昨午 Cursor 栏留空未收；本晨补收并纳入 10 月 30 日 IoC 更新。与 Anthropic 官方 Claude Code 发行渠道无直接等同关系。

交叉核对

  • 多方一致：Cursor 通告与 Sophos 在曝光窗口、SSH 后门意图、需清持久化而非只卸扩展三点一致。
  • 分歧：Sophos 文本侧重 2.1.313；Cursor 通告同时列出 2.1.312 与 2.1.313 及多架构哈希。
  • 待确认：实际成功隧道登录比例；企业侧检出覆盖率依各家 EDR 遥测。
