Claude / Anthropic

Claude Max 5x / 20x 更名为 Max / Ultra；已验证 Ultra 取消五小时限额

Anthropic 10 月 30 日通过官方账号宣布：原 Max 5x 改称 Max、Max 20x 改称 Ultra，月费仍为 100 / 200 美元；已验证的 Ultra 账户将取消五小时用量窗口限制，周限额仍在。

2026-10-31 Claude / Anthropic

Claude 官方账号发帖写明更名映射：Max 5x → Max，Max 20x → Ultra；价格不动，老用户无需改订。The Verge 同日短讯确认了这一命名整理，并点出苹果芯片产品线也用过 Max 后再接 Ultra 的命名习惯——只是类比，不是产品合作。

更实质的变化落在用量策略：Anthropic 称正在取消已验证 Ultra 账户的五小时限额，多数存量订户从当天起分批生效；较新的 Ultra 订户会暂时保留限制，待账户验证完成后邮件通知解除。周限额并未取消，因此 Ultra 仍不是「完全不限量」，只是去掉了短窗节流。

对本窗读者的含义：若你按「5x / 20x」倍率理解套餐，文档与账单很快会改成 Max / Ultra；计费金额不变，但高峰连用时的短窗封顶对已验证 Ultra 会松一档。企业与 API 侧计费口径不在这次更名声明里，勿与昨午已收的 Usage/Cost Analytics API beta 混为一谈。

窗口边界：Claude for Legal、企业报表与问卷池化预算等更早条目不回炒。本条只写 10 月 30 日更名与 Ultra 五小时限额调整。

交叉核对

  • 多方一致：Claude 官方 X 帖与 The Verge、Windows Report 等转述在价格与更名映射上一致。
  • 分歧：五小时限额解除的具体验证流程与覆盖节奏，官方帖只写「多数存量先动、新户待验证」。
  • 待确认：周限额数值、各区域生效时间表以账户邮件与控制台为准。
