Windows 11 十月可选预览更新 KB5127936：右键菜单可定制、云重建等

微软于 10 月 28 日发布面向 Windows 11 25H2/26H2 的可选非安全预览更新 KB5127936（内部版本 26200.9818 / 26300.9818）。亮点包括可自定义的资源管理器右键菜单、云重建恢复、放大镜与讲述人增强等。

2026-10-29 操作系统与桌面

支持页写明这是生产质量改进包，经「渐进推送」与「正常推送」两阶段。渐进部分里，资源管理器右键菜单可更快打开，并提供「自定义菜单」：开关内置命令、调整扩展位置、把剪切/复制等从图标行改回文字项等。地址栏支持用 ~ 直达用户配置目录；文件夹选项对话框补上深色模式。

恢复侧，「云重建」允许用 Windows Update 拉取映像与驱动重装，不必自备 U 盘；可在设置的恢复页发起，或在反复启动失败进入 WinRE 后选择。还支持驱动器清理/硬件擦除、以及 IT 通过 Recovery CSP 远程触发。WinRE 可自动复用本机已存 Wi-Fi 配置以便恢复时联网。

无障碍与其他：放大镜增加对比主题与每显示器缩放、视口锁定；讲述人支持在受支持的 Office 与浏览器中读数学公式；实时字幕可选择是否收录读屏软件声音。另有任务栏预览动画、Phone Link 在开始菜单悬停预览、IPv6 CLAT、内存完整性扩大启用等。正常推送部分含 Edge 加速启动、远程桌面与 Smart App Control 等已知问题修复。

边界：可选预览，不是强制安全补丁星期二包；部分功能视设备与市场渐进到达。已知问题仍列出部分 USB Audio Class 1.0 设备在更早安全更新后的异常，微软称仍在处理。昨晨已收 macOS 27.2，本窗只收 Windows 侧。

交叉核对

  • 多方一致：微软支持页日期 10-28、KB5127936、25H2/26H2；右键菜单定制与云重建为官方亮点。
  • 分歧：Insider 更早预览构建与正式可选包版本号不同，以支持页 26200.9818/26300.9818 为准。
  • 待确认：各功能在渐进环的到达比例；USB 音频已知问题的后续修复包。
