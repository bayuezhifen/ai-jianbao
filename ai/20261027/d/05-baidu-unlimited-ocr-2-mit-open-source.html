Hugging Face 模型卡标注 2026/10/27 发布。3B 级视觉语言模型，稀疏参考滑动窗口注意力把逐步解码成本压住；权重 MIT，配套 GitHub 与技术报告。

2026-10-27 开源治理与许可证

百度在 Hugging Face 发布 Unlimited OCR 2，模型卡写明 2026/10/27 推出。定位是把成百页的书、年报、卷宗等超长文档一次解析成带阅读顺序的结构化文本（含表格、公式、标题等）。核心改动是 Sparse Reference Sliding Window Attention（SR-SWA）：把文本–视觉注意力压缩到固定规模的工作参考集（示例约 512 token），使逐步解码延迟与显存近似不随页数线性爆炸。

规模与许可：约 3.34B 参数，MIT 许可；推理支持 Transformers 快速试跑与定制 SGLang 服务。百度自报在 MPDocBench（数十页级）总分约 84.6、在 MarathonDocBench（百页级）约 77.1，并称在自测对照里显著高于若干闭源与开源对手；标题层级等子项仍是短板。MarkTechPost 等同日梳理强调：基准多为百度自报图表，MarathonDocBench 未见完整公开题集，外部复现仍待社区。

为何放进「开源治理与许可证」：本窗重点是 MIT 权重与可复现仓库落地，而不是百度云商业 OCR 套餐。前代 Unlimited-OCR 已在 6 月开源；第 2 版把「多页」推进到「有限上下文下的近似无限地平线解析」叙事，并警告默认注意力偏置等配置可能导致数百 MiB 峰值分配、需调参防 OOM。

边界：不把公司自报榜单写成第三方权威排行；不把「unlimited」理解成无算力上限。许可证以仓库与模型卡 MIT 声明为准。不回炒 DeepSeek-OCR 等更早相关工作，仅作谱系背景一句带过。
