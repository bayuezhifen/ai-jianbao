OpenAI 发布 GPT-6.1 Terra：更快更便宜的计算机操控与视觉推理

OpenAI 10 月 26 日推出 GPT-6.1 Terra：面向工作日计算机操控与视觉推理的快速高效模型；API 标识 gpt-6.1-terra，标准价约 $1 / $0.05 / $5 每百万 token（输入/缓存输入/输出），较 5.6 Terra 与 6.1 Sol 标价约低一半。

2026-10-27 OpenAI

OpenAI 在官方博客宣布推出 GPT-6.1 Terra，定位为「快、省、能干活」的计算机操控与视觉推理模型，相对 GPT-5.6 Terra 有明显跃升，并强调写作更清晰自然。适用场景包括起草方案、解读技术图纸、填表、剪辑视频一类「填满工作日」的沟通与桌面任务。The Verge 等媒体同日复述：模型已对 Plus、Pro、Enterprise、Edu 用户在 ChatGPT Work 与 Codex 可用，开发者可通过 API 调用 gpt-6.1-terra。

定价是本条的核心卖点之一。标准 API 价格为每百万 token：输入 1 美元、缓存输入 0.05 美元、输出 5 美元——官方称较 GPT-5.6 Terra 与 GPT-6.1 Sol 的标价约低 50%。同用量额度下，ChatGPT Work / Codex 能跑更多任务，尤其相对 6.1 Sol 与 6 Astra 更「省额度」。对要批量读发票、录入财务系统、跑桌面代理流水线的开发者，单价腰斩往往比再抠一两个基准分数更有意义。

评测叙事上，Agents’ Last Exam 中等推理强度下比 5.6 Terra 高约 15 个百分点、成本约三分之一；中等强度下表现可接近 6 Astra，而每 token 价约为其十分之一；最大努力下相对 Claude Opus 5.5 有更高 token 效率与更低单任务成本，且完成速度显著更快。视觉与桌面代理方面，MMMU-Pro 上全面优于 5.6 Terra；OSWorld 2.1 中等推理下以更低成本超越 5.6 Terra 最佳分。事实性上，内部易错提示基准低推理错误率从 53.6% 降至 16.7%；最大努力约 4.3%。Terminal-Bench 4.0 最大努力约解 50.3% 任务，超过 5.6 Terra 公布的 21.5%；最复杂编码仍建议用 6.1 Sol 或 6 Astra。

安全侧称达到 Preparedness Framework 网络安全 Critical 门槛，并继承 6 系列对齐改进与较强提示注入抗性。边界：本条依据官方发布与媒体复述，不回炒昨午「折扣挖 Anthropic 大客户」商业战叙事；也不把 Terra 写成取代全部旗舰模型。复杂研究与顶尖编码仍指向更贵的 Sol / Astra 档。
