CISA 将 PHP「php2shell」CVE-2026-109618/109619 列入 KEV，敦促立即修补

CISA 告警 10 月 26 日修订：将 CVE-2026-109618 与 CVE-2026-109619（合称 php2shell）列入已知被利用漏洞目录；未授权远程代码执行，影响对外提供 Web 请求的 PHP 安装，敦促立即升级。

2026-10-27 漏洞与勒索

美国网络安全与基础设施安全局（CISA）关于 PHP 严重漏洞的告警于 10 月 26 日再次修订：确认将 CVE-2026-109618、CVE-2026-109619 列入 Known Exploited Vulnerabilities（KEV）目录。漏洞被称作「php2shell」，可造成未授权远程代码执行。影响面包括所有对外服务 Web 请求的 PHP 安装，示例环境含 Apache 加 mod_php（PHP 视为风险最高）、PHP-FPM、php-cgi、FrankenPHP、LiteSpeed 等。KEV 入库通常意味着联邦机构与大量对标合规的企业开始进入强制修复时钟。

修复版本：升级至 PHP 8.5.12、8.4.27、8.3.36 或 8.2.35。仍使用已不受支持的 8.1 及更早版本、或无法立即打补丁的系统，CISA 敦促将基于 PHP 的系统下线直至完成修补或升级；Web 应用防火墙仅可作为过渡缓解。行动清单还包括全组织清点 PHP 组件（常嵌在其他软件中不易直接发现）、优先处理互联网暴露面，并监控 PHP 工作进程拉起 shell 或下载工具等可疑行为。

告警链出 PHP 官方安全通告与加强安全流程的博客，以及 NSA、英国 NCSC、澳大利亚 ACSC、荷兰 NCSC、新西兰 NCSC、加拿大 Cyber Centre 等伙伴材料，并提供 SIGMA 检测规则仓库。说明这不是单一美国联邦通告，而是多国 CERT 同日或近窗共振的高优先级漏洞事件。

对运维含义：「先下线再升级」对遗留 8.1 业务尤其痛苦，但未授权远程代码执行的利用面不给观望空间。本条不提供利用细节或概念验证，只传达补丁版本、下线建议与监测方向。不回炒本窗外已收的其他漏洞主条。

简报口径：标题与摘要强调「已入 KEV、立即修补」；细节页补充影响面与多国联动，方便安全团队直接对照工单。

交叉核对

  • CISA 告警修订 10/26：两 CVE 入 KEV；php2shell；未授权 RCE。
  • 补丁：8.5.12 / 8.4.27 / 8.3.36 / 8.2.35；8.1 及更早应下线。
  • 辅：告警链出 PHP 官方安全通告与多国 CERT。
