2026-10-20 Grok / xAI

因下午版会覆写同一日路径 /ai/20261020，Grok 栏不按「空徽章」处理：晨报主条仍是本窗最佳公开产品新闻——官方账号 @bot 宣布可将 Grok Bot 设为 iPhone 操作按钮一键语音（需 iPhone 15 Pro 或更新机型、App 升至 1.16，在「设置 → 操作按钮 → 快捷指令」选择「Grok Bot → Start Voice Chat」）；马斯克此前多次转发用户案例，并写过「maybe your favorite employee」「Hire Grok @Bot today」。

午间增量来自马斯克本人：世界时约 04:41（上海约 12:41）发帖「True, try Grok @Bot」并引用用户称「直接起一个新 Bot、告诉它要什么，像魔法」；同窗稍后回复 John Carmack「Grok’s engineering analysis is good」。这些表态继续给代理产品背书，谈的是使用体验与工程分析能力，不是 API 主型号换代公告。

版本档位按惯例再核：截至今午，docs.x.ai 模型与定价页仍列出 grok-4.7，并写「For everything else, including code, use Grok 4.7」；全文未见 grok-4.8 / grok-4-8。文档中另有 grok-4.20 等既有条目，不能写成「4.8 已上线」或「4.7 已取消」。xAI 新闻页本窗无新的旗舰模型稿；马斯克本窗亦无关于「4.8 取代 4.7」的定量新帖。

对读者的取舍：若只盯 API 版本号，本窗仍无阶梯变更；若关心代理产品，Action Button + 马斯克午间再推说明 Bot 继续往「少打开网站、多交给代理」走。Android 对等捷径、通话结束后长任务是否续跑，官方仍未系统说明。支付与连接器授权风险并不因侧键消失。

交叉阅读：把晨报 Action Button、昨午「自有电脑」与本午「True, try Grok @Bot」连起来，看到的是入口与执行环境持续加厚；把这些与 docs 再核连起来，仍是「产品很吵、型号很静」。在没有 xAI 新闻稿或 docs 变更日志宣布 4.8 之前，简报拒绝被二手「4.8 取代 4.7」带节奏。
