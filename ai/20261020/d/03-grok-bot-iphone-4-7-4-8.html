Grok / xAI

Grok Bot 上 iPhone 操作按钮；马斯克称或成「最爱员工」；再核仍 4.7、无 4.8

@bot 官宣可把 Grok Bot 设为 iPhone Action Button 一键语音；马斯克本窗称「maybe your favorite employee」并多次转发用户案例。docs.x.ai 再核仍列 grok-4.7，未见 4.8，未取消 4.7。

2026-10-20 Grok / xAI

北京时间 10 月 20 日凌晨前后（世界时 10 月 19 日晚），官方账号 @bot 发帖：「Grok Bot is now one step closer. Set it as your iPhone's Action Button and press it to talk with Bot.」附演示视频：侧键一按，灵动岛出现呼叫态，再进入与 Bot 的语音会话。后续说明帖写明：需 iPhone 15 Pro 或更新机型，将 Grok Bot 升级到 1.16，再到「设置 → 操作按钮 → 快捷指令」选「Grok Bot → Start Voice Chat」。

同窗马斯克本人继续给代理产品加压：世界时约 16:27 发「Grok @Bot might turn out to be your favorite employee」并引用用户长文；更早还有「Hire Grok @Bot today. You won’t regret it.」以及转发「笔记本上几乎什么都能干」等用户反馈。这些帖子谈的是 Bot 代理能力与使用体验，不是 API 主型号换代。昨午已收的「自有电脑 / 特性清单 / 电话订座」叙事在本窗被 Action Button 这条硬件捷径接上——少解锁、少找 App，更接近「想到就丢给代理」。

版本档位按惯例再核：截至今晨，docs.x.ai 模型与定价页仍列出 grok-4.7，并写「For everything else, including code, use Grok 4.7」；全文未见 grok-4.8 / grok-4-8。文档中另有 grok-4.20 等既有条目，不能写成「4.8 已上线」或「4.7 已取消」。xAI 官方新闻页本窗无新的旗舰模型稿；马斯克本窗也未见关于训练进度或「4.8 取代 4.7」的定量新帖。

对读者的取舍：若只盯 API 版本号，本窗仍无阶梯变更；若关心代理产品，Action Button + 马斯克背书说明 Bot 继续往「语音优先、少打开网站」推进。Android 是否有对等捷径、一键通话挂断后长任务是否续跑，官方尚未说明。支付与连接器授权风险并未因侧键消失。

交叉阅读：把本条与昨午「自有电脑」帖连起来，看到的是入口（侧键）与执行环境（云端电脑）同时加厚；把本条与 docs 再核连起来，看到的仍是「产品很吵、型号很静」。在没有 xAI 新闻稿或 docs 变更日志宣布 4.8 之前，简报拒绝被二手「4.8 取代 4.7」带节奏。
