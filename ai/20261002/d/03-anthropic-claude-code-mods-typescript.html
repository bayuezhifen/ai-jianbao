Anthropic 推出 Claude Code Mods：用 TypeScript 改写行为与界面

Anthropic 10 月 1 日宣布 Claude Code Mods 正式可用：以事件钩子改写提示、拦截工具调用、处理权限并定制界面；以插件分发，CLI 与桌面端同步，并警告与宿主同权、勿装不明来源。

2026-10-02 Claude / Anthropic

Mods 被写成「几行 TypeScript 就能改 Claude Code」的扩展层：每次工具调用、权限询问或界面绘制都会发出事件，Mod 可在事件前、后或替代执行，也可包裹整段流程。官方举例包括改写发往模型的提示、拦截／重试 Bash 等工具调用、批准或拒绝权限、在工具输出进模型前脱敏，以及替换终端／桌面端局部 UI、增加按钮与输入控件。

分发路径沿用插件：通过 Claude 目录或 CLI 的 /plugin 安装；内置功能开始拆成 Mod，例如 /diff 已可关闭或用自研版本替换，公司称未来会把更多内建能力外置，留下更小的核心。用户还可直接让 Claude Code 生成 Mod、安装并热加载。Team／Enterprise 与托管设置环境下，内置 sec-default 会优先加载，限制用户安装的 Mod 覆盖拒绝规则等危险操作；管理员也可自管优先加载列表。

安全口径很直白：Mods 没有沙箱，权限与 Claude Code 本身相同，只应从信任来源安装。CryptoBriefing 等二手亦指向 ClaudeDevs 10/1 公告，并举 Token Weather、Blast Radius、Replay Theater 等示例插件说明侧栏与风险提示能力。

与晨报区分：今晨 Claude 栏为巴克莱扩大部署，未写 Mods；本卡为晨报截稿前已发布、但未入库的产品增量。Function Hooks 预览与正式 Mods 命名以官方博客为准。
