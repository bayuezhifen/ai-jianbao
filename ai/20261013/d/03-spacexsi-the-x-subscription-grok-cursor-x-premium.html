SpaceXSI 推出 The X Subscription：Grok、Cursor 与 X Premium 统一订阅

昨夜 SpaceXSI 宣布将 Grok、Cursor、X Premium 合成一套 The X Subscription；马斯克转发。现有用户可继续旧套餐或自愿切换。再核旗舰仍为 Grok 4.7，未见 4.8、未取消 4.7。

2026-10-13 Grok / xAI

本窗最硬的 Grok/xAI 产品新闻不是版本号，而是计费与账号统一。约 2026-10-12 23:08 UTC（上海 10/13 约 07:08），@SpaceXSI 发帖：「We've unified plans across Grok, Cursor, and X Premium. Introducing The X Subscription。」马斯克随后转发。官方文档（docs.x.ai）与 Cursor 帮助中心同日可核：一套订阅打通社交（X）、对话/智能体（Grok）与编程 IDE（Cursor）。

档位与用量（以官方定价页列表价为准，含税另计）：Free / Plus（约 8 美元/月）/ Premium（约 30）/ Super（约 100）/ Ultra（约 200）；年付有折扣。Grok 与 Cursor 共用每周「含用量池」；第三方模型（如 Cursor 里的 Claude、GPT）不计入含用量，从首次调用起按 API 价从预付额度扣。Grok Bot 写在 Premium 及以上档，用量同样抽共享池，并非另加配额。团队档按座位提供集中账单与用量分析。

迁移规则写得很清楚：现有 Cursor、SuperGrok、X Premium 可继续；切换自愿，但一旦切换不可撤销。切换时符合条件的旧订阅取消并按剩余时间按比例退款；经 Apple App Store 购买的 Cursor 需用户自行在系统设置取消，官方无法代退。新客默认走上 The X Subscription；企业客户切换路径仍有限制。Cursor 文档亦说明：工作区账单在 grok.com/dashboard 管理。

版本阶梯再核（强制）：打开 x.ai/news，最新模型主条仍是 2026-09-21「Introducing Grok 4.7」；未见 Grok 4.8 发布公告、定价或模型卡。二级跟踪页（ArtificialWatch、VNHAX 等）仍写 4.8「尚未在公开 API 应答」。若有标题写「4.8 取代/搁置 4.7」，本窗没有马斯克或官方可引用的取消声明——现网旗舰仍是 4.7，4.7 未被取消。昨午已收的 Bot「全天候雇员 / iPhone 代购」叙事本窗不回炒；昨夜另有用户晒 Bot 剪辑 Starship 素材等演示，属同一能力线，不单列新品卡。
