英特尔 OCP：Crescent Island 定名 GPU D 系列，首款 D270 客户送样中

同场圣何塞 OCP，英特尔公布面向推理的 GPU D 系列规格：最高约 480GB LPDDR5X、1.3 PFLOPS FP8、350W 风冷 PCIe。晨报只收了英伟达与 AMD，本条补漏。

2026-10-13 CPU / 服务器

在 2026 OCP Global Summit，英特尔新闻室发文《Intel Accelerates Open Infrastructure for the Agentic AI Era》，把原代号 Crescent Island 的推理加速卡正式归入 Intel GPU D-Series，首款型号为 D270。定位写得很清楚：不是去和旗舰训练卡拼峰值，而是在标准 PCIe、风冷、约 350W 功耗包络里，把大容量内存与 FP8 矩阵算力配给持续推理与智能体编排。ServeTheHome 同日梳理规格表，并提醒读者：这是成本与能效导向的推理卡，理论算力低于同形态的部分竞品旗舰属预期内。

公开规格（新闻室与 ServeTheHome 交叉）：Xe3P 架构，约 32 个 Xe 核、256 个 XMX；峰值矩阵约 1.3 PFLOPS（FP8）；内存带宽约 1.5 TB/s；英特尔自有卡标配 160GB LPDDR5X，ODM 可做到最高约 480GB。单卡号称可扛约 3000 亿参数量级模型，八卡系统可上到约万亿参数——属厂商口径，实机表现待第三方评测。接口为 PCIe Gen5 x16，强调可塞进现有机架、不必专做液冷机柜。产品页已挂出 D-Series 条目，但上市日与标价本窗未宣布。

同稿还展示基于 Xeon 的 Open Rack v3（ORv3）机架参考设计，称部分配置可做到每机架超过约 4.6 万核、整架功耗约 133.45 kW，用来承接智能体工作流里的编排、I/O 与通用计算。软件侧强调上游框架集成、跨 CPU/GPU 可移植，以及 Day 0 支持开源模型（文中点到 Meta Muse Glimmer）。客户送样已开始；ServeTheHome 判断量产节奏更可能落到 2027 年，现阶段不宜把「送样」读成「现货开卖」。

命名上，英特尔没有沿用 Data Center GPU Max / Flex 旧品牌，而是新开 D-Series；首款公开渲染图是双槽风冷 PCIe 卡形态。新闻室还提到 Open Adapter Card 工作组贡献，意图统一子机架加速卡机械电气接口。对采购方而言，本窗能确认的是：规格公开、送样进行、OCP 展台可见；不能确认的是到货季度、ASP，以及相对 MI350P 等竞品在真实 prefill/decode 上的能效比。

与晨报对照：晨报 CPU 栏只收了 AMD Helion，英伟达栏收了 Vera Rubin 机架开源与 400G/Spectrum-6。英特尔 D 系列同属本届 OCP 硬件浪潮，但晨报未单列，故午后补进 CPU/服务器栏。不与 AMD Helion、英伟达机架写成「取代」关系——三家都在讲开放异构与智能体机架，读者宜分栏对照规格与供货节点。存储侧三星 HBM5/CXL 展台策略另有韩媒报道，因与昨午 HBM4E 中介层线重叠且缺可点官方英文主帖，本窗不单开存储卡。
