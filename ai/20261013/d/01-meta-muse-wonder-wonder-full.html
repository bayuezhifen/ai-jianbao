Meta 发布 Muse Wonder / Wonder Full：自称首款前沿级智能体模型

10 月 12 日 Meta 推出 Muse Wonder 与更强的 Muse Wonder Full，强调 Active Memory 与长程任务；API 先上 Wonder，Wonder Full 仅 Muse Code 订阅可用。

2026-10-13 行业

覆盖窗口内（昨午约 14:00 至今晨），Meta 于 10 月 12 日正式发布 Muse Wonder 系列：Muse Wonder 与 Muse Wonder Full。公司新闻稿与研究博客将其定位为「迄今最强、面向个人与专业智能体任务」的模型，并称这是重组 AI 业务后首次推出对标前沿梯队的产品线。TechCrunch 等媒体也按「Meta 首款前沿模型」口径报道。

产品侧重点不在堆参数口号，而在智能体能力：Active Memory（跨对话记住与你相关的信息并在任务中主动调回）、Active Focus（遇阻改路、长程跟进、重要动作前确认）。官方演示覆盖保险理赔、租约解读、长程编程与跨应用规划等场景。公司自测称 Wonder 系列在记忆、领域任务与编程等评测上接近或对标 Fable 5.1、GPT-6 Astra 一档；独立第三方全面复核仍需时间，应以官方模型卡与后续公开评测对照。

可用性与定价分层清晰：Muse Wonder 今日起可通过 Meta Model API 与 Muse Code 使用；Muse Wonder Full 仅对 Muse Code 订阅用户开放，不进公开 API。媒体援引 API 价约每百万输入 4 美元、输出 20 美元，大致落在当前主流前沿模型区间。Wonder 还将陆续接入 Muse 产品，优先面向订阅用户。

安全与口径上，Meta 称按《Meta Superintelligence Scaling Framework》训练与评测，强调不擅自外泄隐私、拒绝真正有害协助，同时保留防御性网络安全用途。公司称完整安全评测报告将另行发布。本窗未见 OpenAI / Anthropic 同日对标发布；勿与昨午已收的亚马逊–Decart 洽谈等行业并购条混读。
