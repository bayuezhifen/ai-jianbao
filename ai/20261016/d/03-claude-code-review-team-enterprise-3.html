Claude / Anthropic

Claude Code Review 正式可用：Team/Enterprise 退出研究预览，多数评审约快 3 倍

管理员可为仓库选 Quick / Standard / Deep；合资格 Enterprise 可在 2027-01-15 前申领至少 1 万美元 Code Review 积分。

2026-10-16 Claude / Anthropic

Anthropic 宣布 Claude Code Review 结束研究预览，对 Claude Team 与 Enterprise 组织正式开放。相对预览期，官方称多数评审耗时大约缩短到约三分之一（约从 20 分钟降到 6–10 分钟），发现结果更聚焦「会进生产环境的问题」，并支持管理员按仓库选择 Quick、Standard 或 Deep 深度。启用路径：管理员在 Claude Code 设置中打开、安装 GitHub App 并勾选仓库；之后新 PR 可自动跑评审。

Enterprise 侧有积分激励：合资格组织可在 2027 年 1 月 15 日前申领至少 1 万美元 Code Review 积分，领取后 30 天内有效，细则以条款为准。Anthropic 称预览期客户反馈集中在「要更安静、更贴合改动规模、更快」，本次 GA 针对这些点做了调校。

昨午已收 Q3 约 168 亿美元与 IPO/新加坡办公室吹风，本条不回炒；中期选举防护与 OTel 公测属 10/15 晨报，亦不重复。交叉核对以 Claude 产品文与多家科技媒体同日报道为准。

交叉核对

  • 多方一致：Team/Enterprise GA；速度约 3×；三级深度可选。
  • 分歧：部分外媒写「最高 5 万美元积分」——官稿写至少 1 万美元，以官稿为准。
  • 待确认：非 GitHub 托管仓库的支持节奏。
