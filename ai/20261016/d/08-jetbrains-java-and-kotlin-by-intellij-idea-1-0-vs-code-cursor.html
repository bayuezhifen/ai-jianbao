JetBrains「Java and Kotlin by IntelliJ IDEA」1.0 登陆 VS Code 与 Cursor

预览结束进入稳定版；与 Cursor 团队协作打磨；需 IntelliJ IDEA Ultimate 订阅（含 30 天试用）。许可写明面向人类使用，纯代理场景许可另议。

2026-10-16 开发者工具

JetBrains 宣布「Java and Kotlin by IntelliJ IDEA」扩展 1.0 稳定版上线 Visual Studio Marketplace 与 Open VSX，可在 VS Code 与 Cursor 中使用与 IntelliJ IDEA 同源的 Java/Kotlin 语言智能：补全、导航、分析、重构、Maven/Gradle/Bazel、JUnit 与调试（含模拟断点与异步栈）等。官方强调这是把 JVM 智能「搬到用户所在的编辑器与代理环境」的一步，并点名与 Cursor 团队密切协作；Cursor 产品侧 Rohan Shah 的引语称开发者可在使用 Cursor 代理的同时获得 IntelliJ 级分析与导航。

许可上，1.0 结束免费预览：试用 30 天后需 IntelliJ IDEA Ultimate 订阅，同一许可覆盖桌面 IDE 与 VS Code 系编辑器。文中明确许可面向人类使用，纯代理调用的许可模式将另发更新。兼容性提示：与 Red Hat/Oracle 等 Java 扩展功能重叠，建议停用后者以免冲突；与 Spring Tools 等可并用。

Cursor 本窗无独立 changelog 新品，故 Cursor 栏标空；本条归开发者工具。交叉来源以 JetBrains 官方博客为主。
