（补录）Rust 1.99.1：修复 wcslen 链接、x86_64 FFI bool 误编译、macOS rust-lld 找 libLLVM

官方博客 10/15 点版本，专修回归；rustup update stable 即可。晨报语言栏为空，午后补录。

2026-10-16 语言 / 运行时 / 框架

Rust 发布团队于 10 月 15 日发布 1.99.1 点版本，明确目标是修复先前版本引入的回归，而非新语言特性。已用 rustup 安装稳定版的用户执行 rustup update stable 即可升级。对 CI 锁版本的团队，建议在变更日志里单独记下这次点版本，避免把「修回归」误当成「功能升级」而跳过。

三条修复值得运维与嵌入式/跨平台团队注意：其一，部分目标在链接阶段缺少 wcslen 符号——LLVM 的 loop-idiom-wcslen 优化可能插入对该函数的调用，而某些目标（尤其 UEFI 上使用 std 的项目）libc 未提供，现已在 compiler-builtins 中补上兜底实现。其二，x86_64 上经 FFI 返回 bool 时，返回寄存器高位可能未按 ABI 零扩展，调用方会看到非 0/1 的原始值；现已重新标记零扩展。其三，macOS 上若不以 rustup 代理方式调用编译器，rust-lld 可能找不到 libLLVM.dylib；现为 rust-lld 写入指向该库目录的 rpath。

官方同时呼吁有条件的用户在本地与 CI 试用 beta/nightly，以便更早发现下一轮回归。本条为晨报漏收补录：发布日落在晨报窗内但语言栏当时标空。本窗未见 Node/.NET/Python 值得单开的新主条，故只写 Rust 这一条。
