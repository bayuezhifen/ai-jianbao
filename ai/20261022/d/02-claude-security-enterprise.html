Claude Security：持续扫代码库并跟踪修复，Enterprise 公测升级

Anthropic 更新 Claude Security：仓库变更后自动跟扫、发现项随修复关闭、可写威胁模型与知识库，并提供 API/MCP。面向 Claude Enterprise，附两月每月 2.5 万美元用量额度。

2026-10-22 Claude / Anthropic

Anthropic 在 claude.com 发文称，Claude Security 不再依赖「有人点一下才扫」：接入 GitHub（含 GitHub Enterprise Server）或 GitLab 等仓库后，先做基线深扫，再按变更风险与复杂度持续跟扫，使发现列表尽量贴近当前代码状态。一个项目可挂多个仓库，便于抓住跨服务信任边界一类问题。

另一处落地是「修完就关掉」：多数修复发生在扫描工具之外，Claude Security 会对照后续提交，把已修的发现标为已修复；若同类问题再现则自动重开。团队可在项目知识库里写入部署方式、安全策略等上下文，并审阅/编辑由系统生成的威胁模型，后续扫描按威胁模型判断严重度与可达攻击路径。新 API 与 MCP 连接器可把发现拉进既有工单或 Claude Code 会话；另有基于角色的访问控制，方便扩大使用面而不放开建项目权限。

产品仍标为 Claude Enterprise 公测。文中称自 4 月公测以来已有数千组织、累计发现超百万漏洞；本次升级使用含 Claude Mythos 在内的全系列模型，且不要求 Cyber Verification Program 资格。促销口径：每月 2.5 万美元免费用量额度，连续两个月，适用至 2026-12-31（以帮助中心条款为准）。

边界：不回炒昨晨蝎神经毒素蛋白结合体、昨午前 Monarch/Nscale 基建谈判，以及 Claude Duet 个人代理预览（若作独立消费向产品可另窗再收）。本条只覆盖企业向安全扫描产品的持续监控能力。
