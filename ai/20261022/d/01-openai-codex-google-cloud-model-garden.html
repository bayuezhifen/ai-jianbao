OpenAI 前沿模型与 Codex 将进入 Google Cloud Model Garden

OpenAI 与 Google Cloud 于 10 月 21 日宣布合作：前沿模型与 Codex 代理工作流将进入 Model Garden，经 Marketplace 结算，数周内正式上线。微软仍是主要云合作方。

2026-10-22 OpenAI

OpenAI 10 月 21 日（约世界时 12:00，上海当晚约 20:00）发文称，公司与 Google Cloud 合作，把 OpenAI 的前沿模型以及 Codex 代理式工作流接入 Google Cloud 的 Model Garden。企业客户可在既有 Google Cloud 环境里直接调用这些模型，并把采购计入 Google Cloud Marketplace 与既有消费承诺。双方表示，面向受监管行业的客户，将叠加 Google Cloud 的访问控制与数据治理能力。

文中还提到，OpenAI 模型随后也会进入 Google Antigravity 与 Gemini Agent，方便按任务挑模型。OpenAI 总裁 Greg Brockman 与 Google Cloud CEO Thomas Kurian 均有表态：前者强调把最强模型与 Codex 放到客户已经在用的平台上；后者强调给客户更广的模型选择。页面明确写：微软仍是 OpenAI 的主要云合作方——这不是换掉 Azure 主渠道，而是多一条分发与部署路径。

对工程与采购团队，眼下重点是「即将 GA」而非「今天就能全量切流量」：公开材料只说数周内上线，并提供申请试用入口。本简报把这条放在 OpenAI 栏目，是因为新闻主体是 OpenAI 的产品分发与 Codex 落地，而不是去写公有云 IaaS/PaaS 扩容本身。

边界：昨午已收内部编码代理关闭/削弱错位监控与 Auto-Review 更新，以及更早的 Orchestra Bio 并购、约 300 亿美元融资传闻，本窗不回炒。同日另有 Rosalind/PerturbAI 脑细胞图谱代理研究与「Patch the Planet」协调披露 PHP 漏洞等文，分别偏科研与安全协作，主产品新闻仍以 Model Garden 合作为首。

交叉核对

  • 多方一致：OpenAI 官方与 Google Cloud 同日口径一致；Model Garden + Marketplace + 数周内 GA；微软仍是主要云伙伴。
  • 分歧：无公开价目与具体可用模型清单；「Antigravity / Gemini Agent」上线节奏未给日期。
  • 待确认：首批上架模型 ID、区域可用性、与 Azure OpenAI 服务的合同并行条款。
