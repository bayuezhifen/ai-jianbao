GTC Berlin：Cosmos 扩充世界模型数据工厂、训练框架与 Nano 仿真变体

英伟达在 GTC Berlin 窗口扩展 Cosmos：Data Factory 五套云原生蓝图、Framework 面向开源骨干的微调/蒸馏/部署技能，以及 Cosmos 3 Nano 多视角仿真变体。相对今晨 OpenShell，这是物理 AI 数据与训练侧另一条主线。

2026-10-22 英伟达 / NVIDIA

今晨已收 OpenShell 安全智能体参考架构；午后同场 Cosmos 工具链更值得单独成条。官方称世界模型帮助物理 AI 理解并模拟真实世界，Cosmos 在开源榜单上多项进前五，并配套数据、训练与优化配方。Cosmos Data Factory 现提供五套蓝图（自动驾驶数据集生成、图像属性增广、事件视频生成、缺陷图像生成、视频天气光照增广），经 GitHub 与 Azure、Nebius、CoreWeave 等渠道可得；Cosmos Curator 也扩到多模态多传感输入。

落地举例：保时捷借 Voxel51 在 Azure 上用 Data Factory 做大众集团共享自动驾驶数据飞轮，官方称有望少做约九成重复实车路测、缩短约八成五开发周期；ANYbotics 用合成视频训练巡检机器人识别泄漏等变化；Ultralytics 用真实图加定向合成缺陷重训 YOLO。训练侧，Framework 以智能体技能形式覆盖 GR00T、Alpamayo、QWEN、Pi0.5 等开源骨干的微调、强化学习、蒸馏量化与推理部署；MicroAGI 把 Cosmos 3 蒸馏到约 80 亿参数 Nano 且称精度不掉。仿真侧新增 Cosmos 3 Nano 变体与配套代码，便于在闭环仿真里测自动驾驶与双臂策略；Cosmos 3 NIM 称在验证配置下推理最高约快一倍，Metropolis VSS 3.3 蓝图称同 GPU 可多盯约四成视频流。

边界：不把 DSX 水电节能、Hyperion 出行联盟或今晨 OpenShell 硬件栈再写一遍；也不把「欧洲金融开源模型」客户案例当成 Cosmos 本体发布。GTC Berlin 会期至 10 月 22 日，后续若有独立硬件或软件大单再开新条。
