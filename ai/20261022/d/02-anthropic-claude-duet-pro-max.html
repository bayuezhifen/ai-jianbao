Claude / Anthropic

Anthropic 推出 Claude Duet：主动式工作代理，美区 Pro/Max 候补预览

Anthropic 开放 Claude Duet 研究预览：独立 App（iOS/Android）与 claude.ai，基于 Opus 5.5，会先找需要你关注的事、后台继续干活，敏感操作须你批准。首批面向美国 Pro 与 Max，候补制，用量与 Claude 共用配额。

2026-10-22 Claude / Anthropic

今晨 Claude 栏收的是 Claude Security 持续扫库与修跟踪；本窗主条换成产品侧更大的一步——Claude Duet。官方定位是「主动找上门」的工作伙伴：每天给简报、盯已连接应用、你走开后仍可在虚拟机与自带浏览器里推进任务，发消息、付款、签字、删除前会摊开动作等你点头。证券交易、账户间转账等即便批准也不做。

能力面：承接 Claude 账号里的记忆、技能与连接器；Marketplace 逾 6000 个连接器（Gmail、Slack、QuickBooks、Stripe、Gusto、LinkedIn、DocuSign、HubSpot、Canva、Shopify 等被点名）；可用 Stripe Link 虚拟卡与 Shopify Shop Pay 做企业采购，真卡号不外泄。安全叙事沿用可信代理框架、Managed Agents 凭证隔离、auto mode 分类器，以及浏览器场景下的注入防护；另称做过红队与外部渗透，并纳入公开漏洞赏金。官方也坦言：早期版可能误判紧急程度，个人杂务（订票等）还不强，尚不能把浏览器画面给你看，且独立于主 Claude App。

同窗旁证：Messages API 新版本号 2026-10-21 去掉 temperature、top_p、top_k——传参会 400；旧版 2023-06-01 暂未废弃。这是开发者破坏性变更，宜另作迁移，不与 Duet 混成一条产品故事。不回炒今晨 Security 持续扫描细节与更早的蝎毒蛋白、Monarch 融资传闻。
