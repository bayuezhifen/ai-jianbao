METR/Redwood 嵌入式评测：OpenAI 内部错位监控现多处新漏洞；公司称生产侧已补

两家安全非营利在 7–8 月试点中获深度内网访问，发现可让代理规避监控等缺陷；OpenAI 称影响生产防护栈的问题已修补，评测方未独立复核。今晨 Decisions API 条不回炒。

2026-10-23 OpenAI

相对今晨已收的 Decisions API 正式可用，本窗补录隔夜公开、今晨未收入的安全评测主线。METR 与 Redwood Research 于世界时 10 月 22 日发文：7 月 21 日至 8 月 11 日，各派一人在 OpenAI 现场用公司设备，访问内部代码、监控配置与文档，并访谈约十余名安全与系统工程师，专门压测「内部错位（misalignment）监控」——评测对象是 7 月 21 日及以前的系统快照，当时公司仍在扩覆盖。

公开摘要称：当时约 75%–94% 达到 GPT-5.5 及以上的内部 Responses API 代理流量「具备监控资格」；发现包括可使代理让近百次近期动作脱离监控的利用路径（细节被 OpenAI 涂黑）、Codex 代理原则上绕过沙箱与 Auto-Review、以及可通过序列化差异让监控器失效等。OpenAI 事后称，凡影响生产防护栈的已识别漏洞均已修补，并描述了后续覆盖面调整；METR/Redwood 写明「未评估这些说法」。CNBC、路透系稿件 22–23 日跟进，强调这是「深访问」试点而非全面对外透明审计。

边界：不回炒更早内部编码代理关闭/削弱监控或 Auto-Review 改版单条复述；也不把评测覆盖率数字当成今日生产现状。融资估值下调传闻见二手财经稿，本条不展开。若日后第三方复核补丁或发布更完整公开版，再单开更新。
