Claude / Anthropic

Google Cloud：Anthropic 托管的 Claude 部署选项正式可用，平台新功能可日零上线

与既有的 Google 托管选项并列：同一套前沿模型与计价、同一套 Cloud 账单；差别在数据处理器是谁、以及 Managed Agents/skills 等平台能力是否日零到位。不回炒今晨 Agent Skills 捐赠 AAIF。

2026-10-23 Claude / Anthropic

相对今晨已收的 Anthropic 向 AAIF 捐赠 Agent Skills，本窗 Claude 侧增量是部署形态。Google Cloud 官方博客日期为 2026 年 10 月 23 日，宣布「Claude Models on Google Cloud（Anthropic managed）」一般可用：Anthropic 在 Google Cloud 基础设施上运营栈并担任数据处理器，客户仍用 Cloud IAM、审计日志与既有账单/承诺消费；Claude Managed Agents（测试）、skills、代码执行等平台能力可在日零随 Claude 平台放出。

对照表写明：Google 托管选项继续满足更严的治理、主权与 CMEK/VPC-SC 等要求，但新平台功能要等集成进 Google 托管基础设施后才陆续出现；两边模型日零、标准价、可抵扣合格承诺。点名可用模型包括 Claude Fable 5.1、Sonnet 5.5、Haiku 5.5、Opus 5.5。Claude 平台发布说明亦在 10 月 22 日记下同一 Anthropic 托管通道及 Opus 5.5 Fast mode。

边界：本条写的是 Claude 产品如何进企业云账单与合规分界，不是公有云 IaaS 新品专栏。不回炒昨午 Duet 研究预览，也不展开 Bedrock/Foundry 等其他云上架旧闻。

交叉核对

  • 多方一致：Google Cloud 10/23 博文宣布 Anthropic 托管选项 GA；Claude 平台 release notes 10/22 已记上线。
  • 分歧：Google 托管侧「新功能滚动到位」的具体日历未逐项公布。
  • 待确认：各区域数据驻留与承诺消费抵扣细则以控制台/合同为准。
