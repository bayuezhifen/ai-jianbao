Cursor 代理可操控本机桌面应用：含 iOS 模拟器点选与键入，自托管需显式开启

@cursor_ai 世界时 10 月 23 日 15:59（上海约 23:59）宣布 Computer Use：代理可在桌面应用里点击、键入并测试自己写出的功能；今晨未收。

2026-10-24 Cursor

今晨 Cursor 栏为空，本窗补收隔夜官方帖。@cursor_ai 写明：「Cursor can now control your computer. Agents can drive desktop apps like the iOS Simulator to test the features they build。」时间戳为世界时 10 月 23 日 15:59，落在昨午 14:15 简报之后、今晨 08:20 之前。RuntimeWire 等二手稿同日跟进，强调代理可从写代码扩展到通过图形界面自测。

官方文档「Computer use and desktop sharing」写得更细：自托管 worker 需显式加 --computer-use，服务端不会默认打开；macOS 走 Cursor Computer Use 辅助应用，需辅助功能与屏幕录制权限；Linux 依赖 X11，可复用已有显示或由 worker 拉起 TigerVNC+Xfce。桌面共享（--share-desktop）仅 Linux，与 Computer Use 分开。托管 Cloud Agents 的能力说明另见 Capabilities 文档。

边界：不回炒今晨已写明空窗的口径，也不把自托管权限配置写成「一键全开」；企业机对辅助功能/录屏的 MDM 策略差异，以实际放量为准。与昨晨 Dynatrace Marketplace 插件无直接关系，本窗不合并叙述。
