Claude Enterprise：Chat 与 Cowork 正式合并为统一体验，新增 Efficient 模式

Pro/Max 九月已合并的体验，现对 Enterprise 正式可用：网页/桌面/手机同一会话里既能快问快答，也能把要跑代码、处理文件的工作丢到 Anthropic 托管的云端继续跑。管理员可按角色授权，并用 Efficient 模式把统一体验锁在 Sonnet/Haiku 以控成本。

2026-10-24 Claude / Anthropic

相对昨晨 Agent Skills 捐赠 AAIF、昨午 Anthropic 托管 Claude 在 Google Cloud 正式可用，本窗 Anthropic 产品主条是面向企业客户的体验合并。官方写明：Chat 与 Cowork 九月已先在 Pro/Max 打通，现在同样能力对 Claude Enterprise 计划正式开放。

合并后的逻辑很直白：对话默认从聊天开始；简单问题仍即时回答；一旦任务需要跑代码或处理文件，Claude 转到公司托管的云端会话继续干，人合上笔记本也不会中断，之后可在网页、桌面或手机接着看结果。既有聊天、项目、连接器、skills 与插件会迁到新体验。

安全口径延续企业侧已有控制：SSO、Compliance API、传输与静态加密，默认不用客户数据训模型。代理式工作在隔离虚拟机里跑，Enterprise 默认关闭网络出口，连接器凭证放在沙箱外。零数据保留（Claude Code）、HIPAA 就绪或客户自管密钥的组织，官方称暂时留在现有配置，不自动切到新体验。

成本方面，计价仍按用量。文中给出效率对照：典型负载下 Opus 5.5 比 Opus 5 约低 40% 账单，Sonnet 5.5 比 Sonnet 5 最多约低 30%。管理员新增四类闸门：Efficient 模式（统一体验只用 Sonnet/Haiku）、按角色的模型授权、组织/组/成员消费上限，以及组级共享月度预算。

边界：不回炒研究预览中的 Claude Duet，也不把形式化验证长文（10/22）塞进本条。企业管理员在组织设置里控制放量；现有客户会收到邮件说明。
