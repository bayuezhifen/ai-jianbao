月之暗面推出 Kimi K3.1 Pro：约 3T 级开源权重路线，1M 上下文，权重拟 11/4 放出

Kimi 官方称 K3.1 Pro 为 K3.1 系列首款、迄今最强 3T 级开源权重路线模型，同步上线 Highspeed 快约 2–3 倍；产品与 API 今日可用，完整权重计划 11 月 4 日前放出。

2026-10-24 行业

相对今晨已收的 OpenAI 训练断网、Claude Enterprise 合并、Nemotron 3.5 Bolt 与美光弃 4F² 等，本窗行业增量落在月之暗面。Kimi 技术博客宣布推出 Kimi K3.1 Pro：自称 K3.1 系列首款，也是目前最强的约 3T 级开源权重路线模型，上下文 100 万 token；同步推出 Kimi K3.1 Pro Highspeed，官方称速度约为 Pro 的 2–3 倍。产品侧今日起可在 Kimi.ai、Kimi Work、Kimi Code 与 Kimi API 使用；完整权重计划不晚于 2026 年 11 月 4 日放出。企业管理员可为组织开启，默认关闭。

能力口径以官方基准表为准：Terminal-Bench 4.0 约 65.7%（官方写明高于 GPT-6 Astra 的 58.2%、略低于 Claude Opus 5.5 的 66.4%）；内部 Kimi Code Bench 3.0 Long-horizon 约 61.2%；BenchCAD 带工具约 92.7%；OfficeQA Pro v2 约 64.4。博客强调在编码、3D 创作、金融研究与代理任务上做了更大后训练算力，并写明对网络攻防相关训练数据做了识别与剔除，同时承认清洗后模型在内部漏洞发现评测上仍强于前代、但低于部分已公开三个月以上的闭源前沿模型。

Bloomberg 等二手稿把这次称作月之暗面自「类 DeepSeek 时刻」以来首个大版本升级。边界：不回炒今晨 MiniMax M3.1 Flash 权重（那是昨午主条）、不把「开源权重路线」写成权重已全部上架——官方写明权重要到 11/4；基准数字以博客脚注与第三方榜单滚动更新为准。

交叉核对

  • 多方一致：kimi.ai 技术博客宣布 K3.1 Pro/Highspeed 今日可用、权重拟 11/4；Bloomberg 10/23 报道升级。
  • 分歧：各媒体对「3T 级」参数表述详略不一，应以官方博客为准。
  • 待确认：开源权重的具体许可文件与 HF/魔搭仓库上线节奏。
