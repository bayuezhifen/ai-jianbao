Windows 11 26H1 可选预览 KB5124006：任务栏四边摆放与智能体进程标记

微软支持文档日期 9/22：面向 26H1（OS Build 28000.3086）的非安全预览包，含任务栏上下左右、精简任务栏、开始菜单尺寸，以及 MXC 进程隔离与 agentic process 标记预览。与今晨 24H2/25H2 的 KB5124010 不是同一条。

2026-09-23 操作系统与桌面

微软在支持站点发布「2026 年 9 月 22 日—KB5124006（OS Build 28000.3086）预览」，适用范围写明 Windows 11 版本 26H1 各版本。这与今晨已报、面向 24H2/25H2 的 KB5124010 是两条线：构建号、功能清单与已知问题都不相同，下午窗单独成卡。

桌面侧「新体验」集中在可发现性：任务栏可摆到屏幕上、下、左、右（搜索框与更小任务栏暂只支持上下）；可开更小任务栏以省纵向空间；开始菜单可选小/大尺寸，并把「Recommended」改名为「Recent」，还可隐藏姓名与头像。Windows 搜索主页简化、结果来源标注更清楚，并新增是否显示网页与商店建议的开关。

对 IT 与智能体场景更扎眼的是平台预览：Microsoft Execution Containers（MXC）引入进程隔离，用来给编码智能体、模型生成代码一类负载划轻量边界；另有 agentic processes 预览——授权组件可给进程令牌打上不透明的智能体标识，并随子进程传递，经 Web Account Manager 认证时会带上该标识。密码学侧新增可把后量子 ML-KEM 作为独立 TLS 密钥交换算法使用。管理面则写明：自 2026 年 9 月起，26H1 将不再包含 WMIC 命令行工具（WMI 本身仍保留）。

已知问题需单独读：9 月 8 日安全更新 KB5124012 及之后包启用后，部分 Credential Guard 保护的机器账户可能与本地 AD 失信，根因与 Machine Identity Isolation 策略有关，微软给出 Intune/GPO/注册表回退与修复安全通道步骤，并称将在后续更新里临时挡住该强制。另有 USB Audio Class 1.0 设备 Code 10 / 无声问题仍在跟进。简报边界：只记可选预览与平台预览能力，不写成「已全面推送」；部署仍以组织环与已知问题章节为准。

交叉核对

  • 一致：微软支持页 KB5124006 日期、构建号、任务栏四边与 MXC/agentic 预览原文可核。
  • 一致：与 KB5124010（24H2/25H2）分列，今晨卡不覆盖本条。
  • 待确认：agentic 标识格式仍可能变更；生产环境是否启用 Machine Identity Isolation 需按域控功能级别自查。
