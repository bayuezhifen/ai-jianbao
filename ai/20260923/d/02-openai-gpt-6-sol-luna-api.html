OpenAI 发布 GPT-6 Sol / Luna：API 标价腰斩，补进晨报漏卡

美东 9/22 下午随 Opus 5.5 同日落地：Sol 面向复杂编程与研究，Luna 面向高吞吐杂务；相对 GPT-5.6 促销价，输入/输出 token 价约减半。今晨只写了 AGMAI，本午补产品卡。

2026-09-23 OpenAI

OpenAI 在 9 月 22 日（美西约 11:00 / 开发者社区帖约 18:16 UTC）扩大 GPT-6 家族：在旗舰 Astra 之外推出 GPT-6 Sol 与 GPT-6 Luna。官方与社区口径称，两者承接 Astra 的对齐与能力改进，但把重点放在「更快、更便宜、能规模化干活」——Sol 偏复杂推理、编程与企业负载，Luna 偏摘要、抽取、快问快答一类高吞吐任务。

价格是主标题。TechCrunch、The New Stack 与 OpenAI 开发者社区一致写到：相对 GPT-5.6 时期的促销价，Sol 现为约每百万 token 输入 2 美元 / 输出 10 美元，Luna 约 0.10 / 0.50 美元，整体约腰斩；OpenAI 把降幅归因于缓存与推理效率，并强调对开发者这是默认价而非短期促销。缓存侧另称默认命中率更高，缓存输入最高可打约九折，且调整推理力度或工具可用性时不必整段使缓存失效。

可用性：ChatGPT Work 与 Codex 面向 Plus / Pro / Business / Enterprise / Edu 滚动放量；API 标识为 gpt-6-sol、gpt-6-luna；Free / Go 可在桌面端试用 Luna；标准 Chat 尚未全量，官方称会全天分批以免挤爆服务。事实性方面，官方称 Sol 在内部「用户举报差错」评估上大约减半，接近 Astra 档可靠性但成本更低；对齐评测也写了相对 5.6 的改善，同时仍坦陈部分「绕过显式拒绝」场景下降有限。

对照与边界：Anthropic 同日早约 90 分钟发布 Opus 5.5，OpenAI 材料里对 Opus 5 / Fable 的比价会被立刻改写——The New Stack 明确提醒尚未有人把 Sol 与 Opus 5.5 正面跑完。今晨简报已写 AGMAI 数学顾问组，未写本产品发布，故按「晨漏补写」入下午窗；不与 AGMAI、亦不与今晨已报的 Opus 5.5 / 英伟达机密计算混成一条。

交叉核对

  • 一致：TechCrunch、The New Stack、OpenAI 开发者社区均确认 Sol/Luna 发布与约半价。
  • 一致：Work/Codex/API 可用性与「Chat 分批」表述多方重合。
  • 分歧：与 Opus 5.5 的性价比尚未有独立头对头评测；OpenAI 材料多对照更早的 Opus 5 / Fable。
