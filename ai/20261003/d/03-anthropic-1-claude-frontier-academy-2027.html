Anthropic 砸 1 亿美元办 Claude Frontier Academy：目标 2027 年底训出一万名前线部署工程师

Anthropic 10 月 2 日官宣 Claude Frontier Academy，承诺投入 1 亿美元，面向企业与咨询伙伴培养「Frontier Deployed Engineers」；首批学员来自埃森哲、贝恩、凯捷、澳联邦银行、德勤、麦肯锡、摩根士丹利、诺和诺德等。

2026-10-03 Claude / Anthropic

公司把企业落地难归因于「会把 Claude 做成生产系统的人太少」。Academy 首个项目是 Frontier Deployed Engineer Residency：先做多日面授与模拟企业部署（从选型、安全评审到交接），及格拿 Claude Resident Engineer 徽章，再进入约 12 周驻场，带着本职 Claude 项目与 Anthropic 工程师并肩，结束考核后授予 Frontier Deployed Engineer 徽章；预计 2027 年初出现首批持证者。

招生靠企业提名，首期班已在旧金山、纽约、伦敦开跑，目标到 2027 年底扩到 1 万人。全球商务拓展负责人 Steve Corfield 强调，课程按 Anthropic 自家工程师的标准设计，毕业者应能设定「企业内部如何建 AI」的标杆。CNBC 同日报道称，此举也发生在市场预期 Anthropic IPO 的背景下，意在补企业侧人才缺口。

对本站窗口：午报 Anthropic 卡为 Claude Code Mods（10/1），未写人才学院。本条是培训／生态投入，不是新模型或新 API。Partner Network 已有大量认证与 Basecamp，Academy 定位更高阶的「能带队落地」人选。

仍待观察：驻场考核标准是否公开、徽章是否可被第三方核验，以及咨询公司报价是否显式绑定该资质。
