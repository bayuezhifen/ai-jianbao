GitHub Copilot 下架多款模型：Gemini 3.5／3.6 Flash、Kimi K2.7 Code、Claude Opus 4.7

GitHub Changelog 10 月 2 日宣布即日起在 Chat、行内编辑、Ask／Agent 与补全等全体验弃用四款模型，并给出 Gemini 3.8 Flash、Kimi K3、Claude Opus 5.5 等替代建议。

2026-10-03 开发者工具

弃用名单与替代对照为：Gemini 3.5 Flash、Gemini 3.6 Flash → Gemini 3.8 Flash；Kimi K2.7 Code → Kimi K3；Claude Opus 4.7 → Claude Opus 5.5。GitHub 称无需手动移除旧模型，但工作流与集成应切到仍受支持的型号；Copilot Enterprise 管理员可能要在模型策略里先放行替代型号，才能在 VS Code 与 github.com 的选择器里看到。

同日 Changelog 另有一条：Copilot code review 支持经 REST／GraphQL API 发起评审并可指定 effort，且 Balanced 已成默认档（该默认切换早前已预告，9 月 28 日生效）。晨报已写 Copilot computer use 公测与 JetBrains Air EAP，午报写异步合并 API GA——本窗开发者工具主条改记模型下架，避免与已见功能预览重复。

对本站：下架是供应侧常态，但对锁定旧模型 ID 的自动化流水线会立刻失败。企业侧应核对策略开关与账单档位是否覆盖 Opus 5.5／Gemini 3.8 等替代。

仍待观察：各地区／计划是否同步下架、替代模型默认配额是否变化。

交叉核对

  • 一致：同日另文确认 code review API 与 Balanced 默认；本报道主条以下架为准，API 作窗口内旁证。
  • 待确认：各 SKU 策略面板是否已默认启用替代型号。
