Meta 开源 Muse Gadgets：ESP32／树莓派可自建 Muse 外设，另推 Home Link 等待名单

Meta 于 10 月 2 日把 Muse 智能体外设的设备 SDK 与固件开源（Apache 2.0），并开放自制 Muse Home Link 的美国订阅用户领取；The Verge 同日晚间报道确认。

2026-10-03 行业

Meta 在 gadgets.muse.ai 上线「Muse Gadgets」说明：开发者可用现成 ESP32 板或树莓派／Linux 设备，通过开源 SDK 把 Muse 接到显示屏、按键、传感器与执行器上。页面写明固件与 SDK 采用 Apache 2.0，并警告「后果自负」——包括变砖、保修失效等风险。

官方点名的玩法包括：彩色电子墨水屏做提醒、HDMI 棒把 Muse 投到大屏、小触摸屏做成类 DIY Muse Charm。另有 Linux SDK，可把闲置树莓派做成家用或本机运维助手，并与 Home Assistant 一类本地 HTTP API 对接。

同期推出的 Muse Home Link 由 Meta 自研，宣称可借助社区技能控制灯具、电视、打印机等已有设备；美国有效 Muse 订阅用户可申请，限量，十月发货。The Verge 引 Meta Superintelligence Labs 的 Nat Friedman 称共生产约 5000 台。

对本站窗口：午报行业卡为谷歌 Project Suncatcher，未写 Muse 硬件开源。本条与桌面端 Muse 的 Full Disk Access 争议分列——后者见操作系统栏目苹果声明。仍待观察：SDK GitHub 仓库更新节奏、Home Link 是否扩出美国，以及第三方板卡兼容列表是否持续扩充。
