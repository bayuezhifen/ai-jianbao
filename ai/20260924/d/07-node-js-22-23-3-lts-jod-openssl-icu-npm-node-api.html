Node.js 22.23.3（LTS Jod）发布：OpenSSL/ICU/npm 等依赖与 Node-API 增强

官方发布说明列出 22.23.3：根证书与 OpenSSL 3.5.8、ICU 78.3、npm 10.9.9、Undici 等更新，并为 Node-API 增加 SharedArrayBuffer 相关能力；属维护向 LTS 点版本。

2026-09-24 语言 / 运行时 / 框架

Node.js 官网发布 22.23.3（LTS 代号 Jod）维护版本。Notable Changes 包括：根证书跟到 NSS 3.125、OpenSSL 升至 3.5.8、ICU 78.3、npm 10.9.9、Undici 6.28.1、Corepack 更新，以及 Node-API 对 SharedArrayBuffer 的 typedarray/external 支持等。另有 HTTP/2 收发 RST 时的安全修复、Windows 任务运行器环境变量转义等补丁。

与今晨开发者工具栏「GitHub Actions 下线 Node 20、JS Action 须改跑 Node 24」是两条线：Actions 运行时强制升级影响 CI 维护者；本卡是 Node 22 LTS 线自身的安全与依赖滚动。仍停留在 20 的项目既要面对 Actions 不可用，也拿不到 22.23.3 这类 LTS 修复。

简报边界：不把点版本写成「重大语言特性发布」；升级前按官方 SHASUM 与发行说明做回归。若团队以 Node 24 为 Actions 目标，22.23.3 仍对本地/生产 LTS 轨道有价值。

交叉核对

  • 一致：nodejs.org/en/blog/release/v22.23.3 为官方主源。
  • 一致：变更以依赖与 Node-API 维护项为主，非新重大语法特性。
  • 待确认：各发行版软件源跟进节奏；与企业镜像冻结策略的冲突面。
