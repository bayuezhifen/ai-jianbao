英伟达开源 NodeWright：GPU 集群主机层「声明式」包管理，原内部 Skyhook

9/23 开发者博客：NodeWright 以 Kubernetes 原生方式安全更新节点 OS/内核/调优，尊重 PDB 与不可中断训练标签；Apache 2.0，Helm 安装，对接 AICR 配方。

2026-09-24 英伟达 / NVIDIA

英伟达 9 月 23 日在开发者博客正式以 NodeWright 之名开源其内部长期运行的 Skyhook：面向 GPU 加速 Kubernetes 集群的主机层包管理器。定位很明确——管的是节点本身（内核参数、系统包、安全代理、崩溃转储、调优），而不是替代 GPU Operator / Network Operator 管加速器与网络。

工作流按 cordon → 等待关键负载结束 → drain → 应用包 → 必要时中断/重启 → uncordon 推进，并尊重 PodDisruptionBudget 与「不可中断」标签，避免长训任务被一刀切。DeploymentPolicy 支持固定、线性、指数批次滚动，按隔间设成功/失败阈值。包以容器镜像交付，自定义资源声明版本与依赖，校验失败会写回 Kubernetes 状态。

与 NVIDIA AI Cluster Runtime（AICR）联动时，可把已验证的驱动/内核/主机配方落到运行中节点；同生态还有 NVCRE（上线前用真实负载验集群）与 NVSentinel（运行时故障监测）。博客提供 Helm OCI 安装示例与公开包仓库，许可证 Apache 2.0。

简报边界：这是运维开源工具发布，不是新 GPU 硅片。IonQ Superion 入驻量子中心见今晨；黄仁勋播客政策口径见本午行业栏，不在此混写。
