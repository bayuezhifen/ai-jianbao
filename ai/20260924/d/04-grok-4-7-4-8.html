午报复核：Grok 4.7 仍为现役旗舰，官方页在线；4.8 未见上线取代

下午窗再核 x.ai 发布页与二手阶梯叙述：Grok 4.7（约 $2/$6）仍在，可在 Cursor、Grok Build 与 API 等渠道调用；无「4.8 已取代并下架 4.7」主源。马斯克此前称 4.8 约 2.5T、训完进强化学习，发布日未官宣。

2026-09-24 Grok / xAI

按站规，Grok/xAI 栏不以「无进展」空白带过。下午窗相对今晨再核：Grok 4.7 仍是 9 月 21 日上线的现役旗舰，官方介绍页仍在，定价仍约每百万 token 输入 2 美元、输出 6 美元，并标明可用于 Cursor、Grok Build、API 及第三方路由。

因此本卡在今晨基础上强化：4.7 未取消；4.8 仍是训练/强化学习阶梯上的下一档，不是已替换旗舰。读者以官方模型页与 API 目录为准，不把预测市场或标题党二次解读当成发版事实。
