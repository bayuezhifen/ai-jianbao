Cursor 上线 Rollouts 与 Security Review：部署健康监视 + PR 可利用漏洞审阅

官方 changelog 标注 9/23：面向 Teams/Enterprise 的两款机器人——Rollouts 按环境报告变更是否健康，Security Review 在每条 PR 上报告可利用缺陷；风格问题仍归 Bugbot。

2026-09-24 Cursor

Cursor 于 9 月 23 日在 changelog 发布「Rollouts and Security Review」。今晨简报仍写「最新正式条目为 9/10 Projects」，属漏检；本午以官方页为准补卡。两款机器人面向交付最后一公里，现供 Teams 与 Enterprise，可在控制台 Automations 启用。

Rollouts：PR 打开时读取 diff 与触及系统，先写一份可编辑的监控计划（风险、预期效果、信号、观测缺口）；部署事件触发后，按环境对照日志/指标/链路，给出 verified healthy / regression detected / inconclusive。发现回归可通知作者，配置允许时开回滚 PR 或交给云端智能体修，但「今天不会自行合并或回滚」。源码托管接 Origin 或 GitHub，遥测含 Datadog 等，功能开关集成「即将到来」。

Security Review：对每条非草稿 PR 发一条审阅评论，聚焦可利用问题（注入、鉴权绕过、密钥入库、SSRF、不安全反序列化、带已知漏洞的依赖变更等），每项含严重度、攻击路径与修复建议；风格与质量仍由 Bugbot 负责。可加团队规则（例如外部调用必须经某客户端）。发布后约 10 天内附试用额度（Teams/Enterprise 大约 50/500 次变更量级）。

简报边界：本卡只记官方 changelog 产品能力，不评测检出率。与今晨「仅 Projects」结论不同——下午以 9/23 条目为准。
