Cursor：Origin App Marketplace 上线，超 20 款应用并开放公开投稿

10/13 Changelog：Origin 现可安装部署、CI、代码评审、安全、监控与项目管理类应用；市场同时向任意开发者工具团队开放提交审核。

2026-10-14 Cursor

Cursor 官网 Changelog 于 2026-10-13 发布 Origin App Marketplace。文中列出已接入的合作方覆盖：部署（Cloudflare、Netlify、Render、Spacelift、Vercel）、CI（Buildkite、CircleCI、CloudBees、Depot、EngFlow、Namespace、RWX）、代码评审（CodeRabbit、Greptile、Tenki）、安全（Artemis Security、Semgrep、Socket Security、Upwind）、监控（Sentry）、项目管理（Linear）。「超过 20 款」是官方概括。

投稿路径写得很具体：在命名空间创建应用（私有）→ 按 Origin API 用 app JWT 与 installation token 收 webhook、回写 check run / PR 评论 → 公开后提交 slug、标签与演示视频（须含安装/卸载与核心流程）→ Cursor 审核上架。另提供 Origin Apps 插件，可按实况 API 文档答疑并协助把现有应用迁到 Origin。

同日 Origin API changelog 还增加了预览态的 PR auto-merge 开关（PUT/DELETE）及对应 webhook，属于平台能力补强，晨报主卡放在 Marketplace 产品入口。本条与 Grok/X 统一订阅分列：订阅见既有 Grok 栏叙事，不在此重复。

对团队：若已在 Origin 上跑仓库，可先装官方合作应用试权限模型；自建应用需准备演示视频与审核周期，上架前不要假设「提交即可见」。
