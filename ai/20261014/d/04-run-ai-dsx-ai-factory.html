英伟达 / NVIDIA

英伟达将 Run:ai 全平台开源，纳入 DSX AI Factory 基础层

10/13 开发者博客宣布：完整 Run:ai 平台与可拆用的 KAI Scheduler、GPU Fractioning Operator、KAI Resource Management、Workload Map 开源；KAI Scheduler 已以 Apache 2.0 捐入 CNCF Sandbox。

2026-10-14 英伟达 / NVIDIA

英伟达 2026-10-13 在 Developer Blog 发文：把收购而来的 Run:ai 工作负载与 GPU 编排能力，作为 NVIDIA DSX AI Factory 的开源基础整包放出。仓库落在 NVIDIA DSX AI Factory 的 GitHub 组织；也可在 NGC 以 Community Product（Helm）安装。文中写明：源码遵循相应开源许可证，NGC 社区版仍须接受英伟达软件许可条款，且不含企业级付费支持。

可独立采用的四块：KAI Scheduler（面向 GPU 的 Kubernetes 调度，含 gang、公平份额、拓扑感知与多种 GPU 共享；已捐 CNCF Sandbox）；GPU Fractioning Operator（把 CUDA 13.4 原生 GPU 分片接到集群，替代原先专有实现）；KAI Resource Management（项目/部门配额与节点池）；Workload Map（把 PyTorchJob、RayCluster、KServe 等异构 CRD 描述成统一工作负载契约）。配套还点名 Model Streamer（加速权重加载）与 Grove（多组件推理编排）等可分开用的项目。

生态侧列出 Crusoe、Mirantis、Nebius、OpenNebula、Rafay、Saturn Cloud、Spectro Cloud、vCluster 等八家伙伴的接入方式。对企业客户，商业版 Run:ai 仍可通过 Mission Control / AI Enterprise 等渠道购买支持。本窗与昨晨 OCP 上的 Vera Rubin 机架开源、昨午英特尔 GPU D 系列分列：一条是推理机架与网络，一条是编排软件开源。

交叉核对以英伟达官方博文为准；多家二手科技媒体同日复述「全平台开源 + CNCF KAI」口径。读者若只关心许可证：调度器走 Apache 2.0 社区路径，整包 NGC 分发另有英伟达条款，部署前应分开阅读。
