Grok / xAI

隔夜马斯克密集演示 Grok Bot 升级；再核旗舰仍为 4.7，无 4.8 公开发布、未取消 4.7

10/13 晚间（美西）至 10/14 凌晨，马斯克连续转发/引用 Bot 独立邮箱、机侧快捷键、到货自动停查物流等能力；官方新闻页最新旗舰仍是 Grok 4.7，4.8 仅见「出来之后」表述。

2026-10-14 Grok / xAI

本窗 Grok 主线是产品侧 Bot，而不是新模型发版。马斯克在 2026-10-13 约 21:45–22:38 UTC（上海 10/14 清晨）密集发帖：引用「Latest upgrades to Grok Bot」、强调 Bot 可申请独立邮箱并协助分析收件箱、可绑定手机 Action Button 即时唤起、以及「Grok Bot 代购的乐高已到货且自动停止查物流」。用户与员工帖显示 Bot 约 0.70.2：可领 @mail.grokbot.com 地址、草稿邮件待用户批准发送、聊天内嵌 Figma/Notion/Canva 卡片、无需另连账号即可检索公开 X 帖与主页等。这些是隔夜可见的增量，与昨午「保留 The X Subscription」叙事衔接但不重复订阅卡本身。

版本梯子再核（晨报必做）：x.ai/news 列表顶部产品帖仍为 2026-09-21《Introducing Grok 4.7》与 10-12《The X Subscription》；docs.x.ai 模型页与发行说明仍以 grok-4.7 为旗舰 API 模型。公开检索未见 Grok 4.8 正式发布、模型卡或 API 标识上线。马斯克 10/7 原话大意是：多数 Bot 简单请求「等 lightning-fast 版 Grok 4.8 出来后」再交它处理——这是未到货的未来时，不是「4.8 已取代/下架 4.7」。二手站点若写「4.8 替换 4.7」，与一手不符。

结论口径：仍为 Grok 4.7；无 4.8 公开发布；没有官方宣布取消 4.7。昨午已强化过的统一订阅卡，晨报不整段回炒，只在版本核验中带过。SpaceXSI/xAI 品牌站与马斯克 X 帖为本条第一来源。

对读者：若关心「能不能叫到 4.8」，答案仍是不能；若关心 Bot 能否替你收邮件、盯快递，隔夜演示给出的是产品能力更新，计费与额度仍跟各订阅档走。
