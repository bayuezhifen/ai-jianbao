xAI 正式发布 Grok 4.7：同价同速强化长任务与防护

官方 9 月 21 日上线；Cursor、Grok Build 与 API 即用，定价仍约每百万 token 输入 2 美元、输出 6 美元。本窗无更新于晨报的新主源；马斯克阶梯仍谈 4.8 及以后，未见取消 4.7。午报覆盖同日页时保留并强化此卡。

2026-09-22 Grok / xAI

xAI（页面署名 SpaceXAI）于 9 月 21 日发布 Grok 4.7，定位为面向编程与知识工作的最强公开型号。官方强调：相对 Grok 4.6，它在困难任务上愿意花更长时间、更勤于自检，并配备迄今校准最好的防护栈；对外服务的标价与速度与 4.6 持平——输入约每百万 token 2 美元、输出约 6 美元——另提供输出速度约翻倍、价格亦翻倍的快速变体。

可用性方面，官方写明可在 Cursor、Grok Build 与 Grok API 使用，也可经第三方编程 harness、模型路由与云平台接入。GitHub 同日 changelog 宣布 Copilot 开始向 Pro 至 Enterprise 等档位放量 Grok 4.7，企业管理员可在模型策略中开关。Decrypt 等二手报道称参数量约 2.1 万亿（相对 4.6 的约 1.5 万亿），并提到补充了 SpaceX 工程相关训练数据；这些数字与数据出处以官方系统卡或后续技术说明为准，本报道不单独升格为已核实规格。

关于版本阶梯：此前窗口多次跟进马斯克关于「本周训完进 RL」的 4.8 表述，以及外界「4.8 是否取代或搁置 4.7」的二手说法。主源事实是——4.7 已正式上线，并非被取消。Decrypt 援引马斯克在 X 上的口径：称 4.7 是「智力、速度与低成本」的组合，并继续勾勒 4.8 为有意义的下一步、4.9 对标 Astra/Fable 档、5 有望冲击前沿；未见 xAI 宣布取消 4.7，也未见官方确认 4.8 已训完并进入强化学习。

午报说明：自今晨约 08:40 至约 14:25，x.ai/news 与上述主源无新的 4.7/4.8 官方更新；同日页 /ai/20260922 被午报覆盖时，本卡按站规保留并强化，不因「本窗无增量」而空白成「无进展」。这是对上午已成条重大发布的显式保留，而不是把晨报短卡原文原样粘贴。

基准方面，官方表格将 Grok 4.7 与 4.6、GPT-5.6 Sol、Fable 5.1 对照，突出 CursorBench 4.0 等长程编程任务上的性价比位置；Decrypt 指出在部分知识工作榜单上仍落后于 Claude Fable 5.1。写作边界：只记「4.7 正式发布 + 同价可用性 + 阶梯仍谈 4.8 及以后」；Copilot 接入细节见晨报开发者工具卡，午报不重复升格；也不把更早的 Voice Transcribe 或 4.6 上云重新写成新品。
