GitHub Copilot 周更：新增 Claude Opus 5.5、GPT-6 Sol/Luna、Grok 4.7，应用侧本地沙箱公测

GitHub changelog 9/25：Copilot 本周加入多款前沿模型，并在 Copilot 应用中推出限制文件/网络/凭据的本地沙箱公测；Slack/Teams/JetBrains/VS Code 同步更新。与今晨 CodeQL 2.27.1 为不同产品线。

2026-09-26 开发者工具

开发者工具栏本窗增量来自 GitHub 官方 changelog《GitHub Copilot weekly releases — September 21》（发布日 9 月 25 日）。与今晨已报道的 CodeQL 2.27.1 不同，本条聚焦 Copilot 产品周更：在模型供给、桌面应用沙箱与各 IDE/协作客户端上同时推进。

模型侧：Claude Opus 5.5 对 Pro+/Max/Business/Enterprise 开放；GPT-6 Sol 同样面向这些档位；GPT-6 Luna 与 Grok 4.7 则覆盖自 Pro 起的更广套餐。应用侧公测「本地沙箱」，用于限制代理对文件、网络与凭据的访问，并支持通过企业托管设置把代理活动接到 OpenTelemetry 监控。

协作与 IDE：Slack 与 Microsoft Teams 支持会话中途换模型、频道默认模型、重复议题检查与更清晰的长任务状态；JetBrains 侧公测「辅助批准」（低风险工具调用自动批准、高风险需确认），并支持组织级 skills/自定义指令；VS Code 1.139 相关说明则提到在 SSH/Tunnel/WSL 的 Dev Container 中跑 Agent Host（渐进推送）。

简报边界：本卡写官方 changelog 已列能力；不把「GPT-6 Cyber 预览」媒体传闻当作 Copilot 已上线功能。Cursor 仍单列栏，changelog 无本窗新条。TeamCity 2026.2 为 9 月初发布，不另开卡。

交叉核对

  • 一致：github.blog changelog 9/25 列出 Opus 5.5、GPT-6 Sol/Luna、Grok 4.7 与本地沙箱公测等要点。
  • 区分：今晨 CodeQL 2.27.1 为代码扫描引擎；本条为 Copilot 周更，二者并存、不互相替代。
  • 待观察：各套餐实际开通节奏与沙箱默认策略因租户而异。
