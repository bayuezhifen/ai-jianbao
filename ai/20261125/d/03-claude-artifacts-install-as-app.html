Anthropic 推出 Artifacts「安装为应用」，可在 Mac 和 Windows 上以独立窗口运行

Anthropic 宣布，Claude Artifacts 的「安装为应用」功能开始在 Mac 和 Windows 客户端以测试版推出。安装后的应用有独立图标和窗口，可按三档权限使用通知、快捷键或访问本机文件，并随原 Artifacts 的修改自动更新。

2026-11-25 Claude / Anthropic

Anthropic 在官网文章中写道，即日起可把日常使用的 Claude Artifacts 做成桌面应用。「安装为应用」正在 Claude 的 Mac 和 Windows 客户端以测试版推开。安装之后，应用会有自己的图标，并在独立窗口里打开，而不再待在 Claude 主程序里面。用户可以把应用分享给其他人；它在动用计算机前需要得到许可，用多少权限由用户决定。应用可以使用 Claude 以及账号里已接通的连接器，底层 Artifacts 被改过之后会自动更新。向 Claude 发出的请求仍计入原有套餐额度。

官方把权限分成三档。默认档只允许应用做浏览器里通常能做的事。应用权限档可以申请桌面上更常见、但又由 Claude 收紧控制的能力，例如置顶窗口、全局快捷键和发送通知，也可以把入口放到 macOS 菜单栏或 Windows 系统托盘。完全访问计算机档则可以申请运行程序，以及读取、修改或删除本地文件，而不必每次再问一次。权限只覆盖当前这一版应用，因此即使用户改的是自己做的应用，每次更新后 Claude 仍会再问一遍。若应用里有一部分来自其他网站，那一部分发生变化时，Claude 不一定会再次询问。完全访问只能授予用户自己制作的应用；在团队和企业方案里，也可以授予本组织成员制作的应用。Anthropic 在安装前并不审查这些应用，因此只应把这一档交给自己信得过的应用。

The Verge 11 月 24 日 23:04（世界协调时，约合上海时间 11 月 25 日 07:04）报道了同一功能，指出安装后的应用可以像浏览器里的网页应用那样使用，也可以申请通知、拦截快捷键、在其他程序之上显示，或被授予对计算机的完全访问。Neowin 随后跟进，并写明：Anthropic 不会在安装前审查应用，因此完全访问只开放给用户自己或（在团队和企业方案中）组织内部制作的应用。文档类 Artifacts，包括 Claude 的文档、幻灯片和表格，不能安装成应用。使用时需要联网并登录 Claude。测试版面向所有套餐推开，但已按 HIPAA 标准配置的组织以及混合部署不能使用；团队方案默认打开，完全访问默认关闭；企业方案要等所有者打开后才能用。

官网上举了若干内部例子，包括分层图像编辑器 Linnet、文件管理器 Phosphor、用 Claude 整理文件夹规则的 Sift、带有 Claude 协助的终端 Tern，以及查看计算机性能的菜单栏应用 Vitals。这些是 Anthropic 自己的演示，不代表外部用户安装后也能立刻得到同样的成品。今晨简报已写 Anthropic 发布的沙箱逃逸评测 Siren，本条是另一项产品进展，因 The Verge 稿件落在今晨 08:20 之前不久，晨报未收入，故于午报补录。

交叉核对

  • 一致处：Anthropic 官网、The Verge 与 Neowin 均确认「安装为应用」以测试版在 Mac 和 Windows 上推出；应用有独立图标和窗口；权限分默认、应用权限和完全访问三档；完全访问仅限自己或组织内部制作的应用；文档、幻灯片和表格类 Artifacts 不能安装；需联网并登录。
