Anthropic 为 Claude Code 加护栏：勿复刻既有具体游戏

Anthropic 工程侧确认：已在 Opus 5.5 的 Claude Code 提示词中加两句，引导模型不要复刻某个既有游戏（即便改名或自称原创）；原创、类型向、以及基于用户自有设计与素材的游戏仍允许。The Verge、Tom's Hardware 11 月初报道。

2026-11-04 Claude / Anthropic

围绕「用 AI 一键移植/反编译复古游戏」的争议升温后，Anthropic 工程师 Addy Osmani 公开回应：公司已在 Opus 5.5 的 Claude Code 提示词里加了两句，核心是鼓励做原创、类型向、或基于用户自己设计与素材的游戏，同时避免复刻某个具体的既有作品——哪怕起了新名字、自称「原创」。他强调用 Claude 去侵犯知识产权违反使用政策，并称会继续调平衡；若误伤了用户自己的作品，可直接反馈。

The Verge（11 月 2 日）与 Tom's Hardware 等交叉报道称，社交平台上已出现疑似新提示词截图；Osmani 未逐字确认截图，但确认了「加两句」与政策动机。媒体同时指出：这是提示词层护栏，不是硬编码过滤器，熟练用户仍可能绕过；也有开发者抱怨正当的引擎移植或学习性复刻被误拒。

背景是近几个月 AI 辅助的游戏反编译、重编译与跨平台移植大量涌现，版权方与平台规则承压。Anthropic 选择先在 Claude Code（偏工程代理）收紧，而不是全面禁止「做游戏」——产品叙事仍欢迎原创与自有 IP。

对开发者工具栏的含义：模型厂商开始把「别帮人搬别人的游戏」写进系统提示，类似此前对恶意软件、生物风险的拒答策略，只是这次目标更贴近消费级创作社区。效果取决于拒答一致性与误杀率；竞品是否跟进同样值得观察。

本条为晨报漏收、午报热点补入（晨报 Anthropic 栏收了 FlashProve）。勿与「全面禁止写游戏」混淆；亦勿把用户传闻中的「反编译一律封锁」写成官方口径——Osmani 声明聚焦「复刻既有具体游戏」。

交叉核对

  • 多方一致：Claude Code / Opus 5.5 提示词新增引导；允许原创/类型/自有素材；禁止复刻既有具体游戏；Addy Osmani 确认；动机为 IP/使用政策。
  • 分歧：截图原文是否一字不差未获官方逐句确认；用户称部分逆向工程请求也被拒，官方声明未展开。
  • 待确认：是否推广到其他 Claude 产品表面、误杀申诉流程，以 Anthropic 后续说明为准。
