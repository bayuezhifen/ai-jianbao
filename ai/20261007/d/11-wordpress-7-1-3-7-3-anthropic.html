WordPress 7.1.3 安全版修复 7 个漏洞，其中 3 个由 Anthropic 报告

WordPress 10/6 发布 7.1.3，修复评论后台存储型 XSS、WXR 导出二阶 SQL 注入、未登录可读取私密文章评论等 7 个问题；Anthropic 报告了其中 3 个，官方建议立即更新。

2026-10-07 语言 / 运行时 / 框架

WordPress 于 10 月 6 日发布 7.1.3 版本，属于安全更新，官方建议所有站点立即升级，后台「仪表盘—更新」即可自动完成。这些修复也同步回移到了受影响的旧分支，但官方提醒只有最新版本处于主动支持状态。

按官方发布说明，本次共修复 7 个安全问题：

一是评论管理页面的存储型 XSS，攻击者可借待审核评论植入脚本，由 Trail of Bits 的 Thomas Chauchefoin 报告；二是 WP_Http::make_absolute_url() 方法的拒绝服务问题；三是 WXR 导出功能中的二阶 SQL 注入；四是作者角色用户可以把文章设为置顶的权限缺陷，后三项均由 Anthropic 报告；五是未登录用户可读取私密或未发布文章的评论，由 Patchstack 的 Ananda Dhakal 报告；六是 Imgur 嵌入内容存在 XSS，由三位独立研究者报告；七是传给 {status}_{type} 钩子的参数可被伪造，导致动作名冲突，由 WordPress 安全团队成员发现。

值得注意的是报告者名单。Anthropic 一家报告了 3 个，延续了近来 AI 公司用自家模型大规模审计开源项目的趋势；本刊晨报提到的 OpenSSH 10.6 也在发布说明中称，AI 生成或辅助的漏洞报告近来明显增多。从利用条件看，评论后台的存储型 XSS 只需提交一条待审核评论，等管理员打开后台就可能触发，对开放评论的站点威胁较直接。

WordPress 占全球网站相当大的比例，核心漏洞一旦公开，自动化扫描很快就会跟上。已开启小版本自动更新的站点通常会自动升到 7.1.3，关闭了自动更新或使用托管面板锁定版本的站点需手动处理。晨报提到的 Ninja Forms 等插件漏洞属于第三方插件问题，与这次核心更新无关，需要分别升级。

交叉核对

  • 多方一致：WordPress 官方版本说明、Patchstack、IT之家对 7 个漏洞及报告者（Anthropic 3 个、Trail of Bits、Patchstack 等）的描述一致。
  • 小出入：官方说明正文写「一项安全修复」，但列出了 7 项，以列表为准。
  • 待确认：各漏洞的 CVE 编号与 CVSS 评分尚未全部公布。
