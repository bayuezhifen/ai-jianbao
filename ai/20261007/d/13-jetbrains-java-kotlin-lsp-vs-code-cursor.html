JetBrains 的 Java/Kotlin LSP 扩展进入候选版：VS Code、Cursor 可用，正式版起需 IDEA Ultimate 订阅

JetBrains 10/6 宣布「Java and Kotlin by IntelliJ IDEA」扩展到达候选版（RC），把 IntelliJ 的 Java、Kotlin 代码理解能力带进 VS Code 及 Cursor 等衍生编辑器，Cursor Agent 也能直接调用；正式版很快推出，试用 30 天后收费。

2026-10-07 开发者工具

JetBrains 10 月 6 日在官方博客宣布，基于语言服务器协议（LSP）的扩展「Java and Kotlin by IntelliJ IDEA」进入候选版（Release Candidate）阶段。这款扩展两个月前首次公开预览，目标是把 IntelliJ IDEA 对 Java 和 Kotlin 的代码理解能力搬到第三方编辑器里，第一站就是 VS Code 和 Cursor 等基于 VS Code 的编辑器。官方称稳定的 1.0 版「很快」发布。

从预览到候选版，JetBrains 发了多个中间版本，主要提升性能和稳定性。扩展在 Visual Studio Marketplace 和 Open VSX 两个市场累计下载已超过 2 万次；JetBrains 自己也在构建 IntelliJ 系列 IDE 的超大代码仓库上内部试用。

功能上，除了智能补全、跳转、代码检查、快速修复等基础能力，扩展还提供项目级重构、基于调试适配器协议（DAP）的调试、Maven/Gradle/Bazel 项目支持、内置测试运行和 Spring 工具互通。对 AI 编程而言更关键的一点是：在 Cursor 里装上这款扩展后，Cursor Agent 可以调用同一个语言服务器做语义级代码搜索、跳转和分析，JetBrains 称这能让智能体的结果更快、更确定。JetBrains 的帮助文档也专门写了在 Cursor 中通过 Open VSX 安装的步骤。

授权方面需要留意：候选版属于抢先体验计划（EAP）的最后一个版本，可免许可证使用 30 天；从稳定版开始，新用户有 30 天免费试用，之后必须订阅 IntelliJ IDEA Ultimate 才能继续使用。也就是说，这不是一个免费的社区插件，而是 JetBrains 把付费 IDE 的核心能力拆出来、按订阅卖给不用 JetBrains IDE 的开发者。

这一步的意义在于，JetBrains 承认了相当一部分开发者已经转向 VS Code 系编辑器和 AI 编辑器，与其守住自家 IDE，不如把最有竞争力的 JVM 代码分析能力输出出去。官方还预告，接下来几周会介绍更多能力，包括完全由智能体驱动的终端工作流。对 Java、Kotlin 项目较多、又在用 Cursor 的团队，正式版定价和与现有 Ultimate 订阅的关系值得关注。

  • 官方数字：两个扩展市场累计下载逾 2 万次。
