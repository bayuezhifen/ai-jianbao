GitHub Copilot for JetBrains：企业可管默认模型，MCP 可关自动启动

GitHub Changelog 10/10：企业托管设置可选任意可用 Copilot agent 模型作新会话默认；新增关闭 Copilot/Claude MCP 自动启动；诊断菜单直达修复。晨报未收。

2026-10-11 开发者工具

GitHub 于 10 月 10 日在 Changelog 发布 Copilot for JetBrains 更新，主轴是「谁决定默认模型」和「工具何时起来」。企业管理员可用托管设置，把任意可用的 Copilot agent 模型设为新对话默认，同时保留显式模型选择器——组织有默认口径，个人仍能改道。

MCP 一侧新增设置：可禁用 Copilot 与 Claude 的 MCP 服务器自动启动，让已配置工具何时激活由使用者或策略决定，而不是一开 IDE 就连上。诊断意图菜单加入 Fix，可打开内联聊天让 Copilot 修问题；有 agent 模式时走 agent，否则走 ask。账号标签、会话按轮分组跳转、用户消息复制/编辑、迁移后返回 Copilot 主页等，属于体验层补强。

兼容性上，官方明确结束对 JetBrains IDE 2025.1 的支持，需 2025.2 或更高。质量说明覆盖语言服务器启动、模型切换、MCP 配置、自定义刷新与 worktree 等路径的稳定性修复。这与晨报 Bun、Cursor changelog（仍停在 10/6 Remote control）都不重叠：Cursor 栏仍空；本条是 Cursor 以外的 IDE 插件。
