Cloudflare 收购 Deno：合并 celld 与 workerd，强化 Workers 自托管

Cloudflare 官方博客称 Deno 团队整队加入，目标是把 Workers / Durable Objects 编程模型做成可自托管的主流写法；TechCrunch 10/10 跟进。晨报未收，本窗补录。

2026-10-11 语言 / 运行时 / 框架

Cloudflare 于 10 月 9 日在官方博客宣布：Deno 团队加入 Cloudflare，并将把 Deno 开源的 celld 与 Cloudflare 的 workerd 合并，重点补齐 Durable Objects 在自托管场景下可横向扩展的实现。Node.js 创始人 Ryan Dahl 写道，加入是为了让 Workers 编程模型成为「构建服务器的主流方式」；Cloudflare Workers 负责人 Kenton Varda 则解释，公司对 celld 的态度是欢迎而非敌意——因为「开放与留下逃生口」本身就是生意。

背景并不复杂：workerd（Workers 运行时）早已开源，但生产级 Durable Objects 路由依赖 Cloudflare 全球网络与大量外部服务，自托管只能做到单实例级测试。Deno 在 8 月放出的 celld 用 Rust 写成，外部只依赖对象存储，目标正是「一台二进制 + 一个桶」就能跑分布式 Workers/DO。两边合兵，等于把「更好的编程模型」和「可自建的运维面」绑到同一条产品线上。

对开发者意味着几件事。第一，Workers 与 Durable Objects 不再被默认写成只能锁在 Cloudflare 上的黑箱；自托管路径会由 Ryan、Bert 等人主导做成一等公民。第二，Deno Deploy 的去向需看官方后续说明——TechCrunch 援引口径谈收购与 Workers 编程模型，金额未披露；Deno 累计融资约 2600 万美元。第三，这与晨报 Bun 1.4.3 的「运行时内置类型检查」是不同故事：Bun 是性能与工具链增量，Deno 是所有权与生态归宿。
