TensorWave 与 OpenAI 达成六年协议，提供 457 兆瓦 AMD 算力

AMD 投资支持的人工智能云厂商 TensorWave 16 日宣布，将在六年内为 OpenAI 提供 457 兆瓦专用、单租户算力，采用 AMD Instinct MI455X 与 Helios 机架级系统。首批产能计划 2027 年上半年投运，全部部署预计 2028 年初完成。

2026-11-17 CPU / 服务器

拉斯维加斯的人工智能云厂商 TensorWave 16 日宣布，已与 OpenAI 达成六年协议，将在美国多个数据中心为对方提供 457 兆瓦专用、单租户算力。系统采用 AMD Instinct MI455X 加速卡，并按 AMD 的 Helios 机架级方案来设计和互联，机架之间使用以太网。双方没有公布合同金额，也没有点名具体机房地点。

按公司说明，第一批产能计划在 2027 年上半年投运，全部部署预计 2028 年初完成。这些机柜将只服务 OpenAI，不和其他租户混用。TensorWave 总裁兼联合创始人彼得·托马西克把这件事概括为：能不能稳定、迅速地交出数百兆瓦的先进算力，正在成为头部实验室挑选供应商的分水岭。AMD 人工智能业务高级副总裁瓦姆西·博帕纳在同一份公告里，称之为面向 OpenAI 的“标志性部署”。

The Next Web 写到，这份协议落在 OpenAI 与 AMD 已有的合作框架下，TensorWave 是双方首次公开点名的“新云”供应商。OpenAI 负责计算资源的首席技术官乌代·鲁达拉朱说，这是在推进公司此前已经宣布的 AMD 合作。TensorWave 目前只使用 AMD 硬件，曾是首家公开部署 MI300X 的公有云厂商，随后又上线了 MI325X 和 MI355X；对这家公司而言，这是迄今规模最大的一次交付。

资本和市场背景也可对照来看。TensorWave 在今年 6 月完成 3.5 亿美元 B 轮融资，投资方包括 Magnetar、AMD Ventures 和 Nexus Venture Partners。公司称已锁定超过 2 吉瓦的长期数据中心容量。需要说清楚的是：457 兆瓦是规划中的交付规模，不是已经上线的算力；2027 年上半年能否如期交出第一批机柜，仍取决于供电、机房和供应链。

在英伟达人事动荡、美国又收紧先进芯片远程访问规则的同一窗口里，OpenAI 把一部分大规模训练和推理产能明确押在 AMD 的下一代机架上，本身就是一条值得单独记下的供应链消息。它并不能自动改写当前的芯片格局，但说明头部实验室仍在为 2027 年至 2028 年的算力提前锁量。
