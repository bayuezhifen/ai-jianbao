操作系统与桌面

Windows Insider 10/16 多通道新构建，并点名 RTX Spark 机型加入生态

Beta / Experimental / Release Preview（含 26H1）同日推送；博客同时提到 NVIDIA RTX Spark Windows 机上市。Ubuntu 26.10 GA 昨晨已收，不回炒。

2026-10-17 操作系统与桌面

微软 Windows Insider 博客在 10 月 16 日宣布向 Beta、Experimental 与 Release Preview 通道发放新的 Windows 11 预览构建。文中列出的编号包括 Beta 26220.9739、Experimental 26340.9750，以及 26H1 通道下的 Beta 28020.3262、Experimental 28120.3272；Release Preview 则分别覆盖 25H2/26H2 与 26H1 对应构建。对跟版本的读者，这是「三通道同日更新」而不是单一 Dev 快照。

功能摘录里，Gaming Task View 在 Xbox 模式下换了导航条，方便边玩边退出到桌面或电源选项；Experimental 通道的 Windows Hello 人脸识别可在暗光环境临时提高屏幕亮度以助登录，开关在「设置 → 账户 → 登录选项」。

同一篇博文用独立小节写到：NVIDIA RTX Spark 驱动的新一批 Windows 11 设备当日上市，并欢迎这些新设备加入 Insider 计划反馈。这与英伟达消费级开售叙事衔接，但操作系统栏的重点仍是 Insider 构建本身，游戏可玩性细节昨午消费电子卡已写过，这里不重复堆砌。

发行版方面：Ubuntu 26.10 已在昨晨窗口报道 GA，本期操作系统栏不回炒。若你只装稳定零售版、不进 Insider，本条对你是「路线图信号」而非立刻要装的补丁。
