Cursor：Cloud Agent 可出 Canvases；Environments API 进 beta，环境更大更快

changelog 标注 10/16：云端代理可构建可分享交互画布；环境可用 API 程序化管理；单环境最多 300 个仓库，大型环境加载约快 5 倍。

2026-10-17 Cursor

Cursor 在 10 月 16 日的 changelog 发布「Cloud Agent Canvases and Environment Improvements」。云端代理现在可以把工作成果做成交互式 Canvas，做完后用链接分享给同事——从「只在对话里交代结果」变成「留下可点、可协作的工件」。官方另链到 Canvas 分享说明，暗示这会成为团队审阅代理产出的一种标准形态。

同条还宣布 Environments API 进入 beta：可用程序创建建与管理云端代理跑在其中的环境，而不是只在 UI 里点选。对要批量开环境、把代理接入自有流水线的团队，这是把 Cloud Agent 从「手工试点」推向「可编排」的一步。

容量与性能：云端环境现支持最多 300 个仓库；大型环境加载官方称约快 5 倍。仓库上限提高后，单体仓与多仓单体组织更容易把相关代码放进同一代理上下文，但也更考验索引与权限隔离——changelog 本身未展开安全模型细节。

本期 Cursor 栏只收这一组官方更新。昨午写「无独立新品」是基于当时 changelog；本窗已出现明确条目，故改写为新闻卡。不与 VS Code 1.142 的本地 Canvas 预览混为一谈：那是 10/14 稳定版 IDE 能力，落在不同产品与更早窗口。
