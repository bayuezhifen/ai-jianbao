OpenAI：Prompt-to-voice 对 API 全面开放，GPT-Live 新增多语种音色

10/16 产品发布说明：可用文字描述生成自定义音色并复用到 GPT-Live；同步上线德/法/印地/日/韩等九个自然音色。昨午已收的 ChatGPT Voice 1.1/Quip 不回炒。

2026-10-17 OpenAI

OpenAI 在 10 月 16 日的产品发布说明里，把 Prompt-to-voice 扩到全体 API 客户：开发者可在 API 或 Voice Playground 用一段文字描述生成自定义音色，再放到 GPT-Live 会话里反复使用。官方写明「生成音色本身免费，真正开口说话仍按常规 GPT-Live 会话计费」。这对要做品牌声线、客服人设或本地化口播的团队，比只能从固定列表里挑声线更灵活。

同日还为 GPT-Live 增加九个自然语言音色：德语 Nuri、Juni、Flitz；法语 Brise、Sillage；印地语 Nira；日语 Harema、Shida；韩语 Noeul。命名偏生活化，方向是「听起来像真人说话」而不是机械播报。

与昨午补录的 ChatGPT Voice「GPT-Live-1.1 / Quip + 多语种 Live 音色」是同一产品线的不同落点：昨条侧重 ChatGPT 客户端体验与口音；本条是 API 侧 Prompt-to-voice 与又一批命名音色。读者不必把两条当成重复换皮，但采购或评测时应分清「ChatGPT 设置里选声」和「API 用描述造声」两条路径。

发布说明未在本窗另给模型换代新闻；算力人事、Rosalind 申请等昨午或更早已覆盖的条目本期不展开。若只关心语音产品，优先读 openai.com/products/release-notes 10/16 两节原文。
