DeepSeek 发布 V4.1-Flash-1017：编程智能体更强、输出更短，Search & Fetch API 同步开放

10/17 官方上线小版本更新：端到端项目与智能体任务表现提升，单任务成本下降；自研搜索接口对全体开放，权重同步开源。

2026-10-18 行业

DeepSeek 于 10 月 17 日发布 DeepSeek-V4.1-Flash-1017，并在官网、App 与 API 同步上线。官方将其描述为相对上一版 Flash 的「帕累托改进」：基准表现更强，任务完成更快，输出更短，从而压低单次任务成本。文档特别提到面向 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 等编程壳的优化，并建议将 Harness 升到 v0.2.1-rc.1 或更新以获得最佳体验。

产品叙事上，公司强调用带自我反馈的强化学习，改善「从零搭完整项目」的能力，并放出紫禁城三维建模、网页赛车、Godot 版 Portal 2 复刻等演示。媒体侧（如 The Decoder、X 上的技术讨论）把重点放在智能体编码基准与成本曲线：在相近或更高通过率下，单任务花费明显低于部分闭源旗舰，这与官方「更短输出、更快收尾」的说法相互印证。

同期开放 Search & Fetch 两个接口，宣称基于自研搜索引擎、日均服务上亿次请求，定价各为每千次调用 0.75 美元。文档写明：经 DeepSeek Harness、Claude Code、Codex 等服务端工具走 Search & Fetch 的调用，对 DeepSeek API 用户暂免，计费自 2026-10-31 16:00 UTC 起。权重同时放到 Hugging Face 与 ModelScope，便于本地与第三方网关接入；Vercel AI Gateway 等也在同日附近宣布上架。

对本窗口的意义：这是昨午简报之后、隔夜到今晨最明确的一条开源侧模型发布，且把「编程壳适配 + 搜索工具变现时间表 + 权重开源」捆在一起，而不是只发一张基准图。是否在真实仓库里稳定超过闭源旗舰，仍需看后续第三方复现与生产负载反馈。
