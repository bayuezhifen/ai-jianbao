马斯克转发：Grok Bot 自有电脑与特性清单；再核仍 4.7、无 4.8

午间马斯克转发「Bot 自有电脑、可关笔记本」及专属邮箱/语音/连接器等清单，强化晨报电话订座叙事；docs 再核仍见 grok-4.7，未见 4.8，未取消 4.7。

2026-10-19 Grok / xAI

因下午版会覆写当日 /ai/20261019，晨报已有的 Grok 主条必须保留或加强。本窗在晨报「可打电话订餐厅 / 像雇能干员工」之上，并入马斯克北京时间午间前后的两条转发：其一强调 Grok Bot「自有电脑」，用户可以关掉笔记本、只用手机 App，除非需要访问本机文件；其二是一份面向普通用户的特性清单——专属邮箱、车内可用的语音、7×24 开网页填表的自有电脑、Gmail/日历/Notion/网盘/X 等连接器、可睡眠时跑的例行任务，以及「多 Bot 分工」与主动提醒。

这些内容与昨午「日更约 20 项、信用卡截图可下单、能挣回费用」同属一条产品线的持续加压，而不是新的模型阶梯官宣。马斯克本人本窗未见关于训练进度、参数量或「4.8 取代 4.7」的定量新帖；转发本身应读作对 Bot 代理能力的背书，而不是对 API 主型号的改口。

版本档位按惯例再核：截至午后，docs.x.ai 模型与定价页仍列出 grok-4.7，并写明「For everything else, including code, use Grok 4.7」；全文未见 grok-4.8 / grok-4-8。文档中另有 grok-4.20 等条目，属于既有命名空间，不能写成「4.8 已上线」或「4.7 已取消」。xAI 官方新闻页本窗无新的旗舰模型稿。

对读者的取舍：若只盯 API 版本号，本窗仍无阶梯变更；若关心代理产品，电话订座、自有电脑与连接器说明 Bot 继续往「少打开网站、多交给代理」推进。支付与授权风险并未因转发消失——连接邮箱、日历、支付凭证仍须用户自己把关。

交叉阅读：把本条与晨报订座帖、昨午日更帖连起来，看到的是代理能力在语音外呼、云端电脑、支付履约三条线上同时铺开；把本条与 docs 再核连起来，看到的是「产品很吵、型号很静」。在没有 xAI 新闻稿或 docs 变更日志宣布 4.8 之前，简报拒绝被二手「4.8 取代 4.7」带节奏。
