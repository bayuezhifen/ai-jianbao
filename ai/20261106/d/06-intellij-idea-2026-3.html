IntelliJ IDEA 2026.3：引入 JetBrains Air，并改进调试与 Git worktrees

JetBrains 11 月 5 日宣布 2026.3：内置/配套 Air 多智能体层、面向 Cursor/VS Code 的 Java/Kotlin 扩展、调试增强、Git worktrees，以及 Java 28 等生态支持。

2026-11-06 开发者工具（IDE、CI、包管理，Cursor 以外）

JetBrains 博客称 IntelliJ IDEA 2026.3 已发布，可通过官网下载、IDE 内更新、Toolbox 或 Ubuntu snap 获取。亮点包括：JetBrains Air——面向智能体开发的新一层，可并行运行多个编码智能体并跟踪会话与变更；面向 Cursor 与 VS Code 的 Java/Kotlin 扩展；调试改进（含 ij-debugger agent skill、Hibernate 调试、HTTP 响应中的 Spring Security 诊断等）；支持在未打开完整工程时做快速任务与编辑；Git worktrees 便于并行开发与代码评审；以及对 Java 28、Jakarta Persistence 4、Hibernate 8、Scala 更新与 Kotlin 对 Spring Modulith 的支持等。

官方 Air 产品页与帮助文档补充：可选择本地或 ACP 兼容智能体，并在临时 worktree 中跑会话、再把结果拣回主工程。另有「What’s Fixed」博文汇总稳定性与性能修复。GoLand 2026.3 同日也有独立发布公告，本简报以 IDEA 主条为代表，不单列。

本条不涉及 Cursor 自家 Live Apps（晨报已收）。
