Microsoft Sysinternals：Autoruns 原生 Linux，Process Explorer 原生 macOS

Microsoft Sysinternals 团队 11 月 5 日更新：首次推出原生 Linux 版 Autoruns，以及 macOS 原生 Process Explorer；并继续更新 Sysmon、Procmon 等跨平台工具。

2026-11-06 开发者工具

据 Neowin 2026 年 11 月 5 日报道与 Microsoft Sysinternals 博客列表，团队发布跨平台重要里程碑：Autoruns 迎来首个原生 Linux 版本，用于查看与管理开机/登录自启动项；Process Explorer 推出 macOS 原生 1.0，提供进程树、属性、性能图与控制能力，并展示苹果硅性能核与能效核等信息。Process Explorer for Mac 已在 GitHub 仓库 microsoft/ProcexpForMac 可见。

Autoruns 在 Windows 上长期是比任务管理器更细的自启动审计工具，覆盖服务、计划任务、驱动等。Linux 原生版此前缺位，用户多依赖第三方仿制；发布当时 Autoruns for Linux 的 GitHub 页一度 404，功能差异仍待官方补充说明。同日博客还汇总了 Sysmon、Procmon、ProcDump for Linux、ZoomIt for macOS 等既有非 Windows 工具的更新。

对混用 Windows/Linux/macOS 的运维与安全人员，这意味着 Sysinternals「同一套心智模型」进一步跨出 Windows。仍须注意：各平台能力并非镜像对等，Linux Autoruns 的覆盖范围要以正式文档与二进制为准。

主源为 Neowin 对官方博客的报道，辅以 GitHub 仓库存在性核对；若官方博文 permalink 变更，以 techcommunity Sysinternals Blog 11-05 条目为准。
