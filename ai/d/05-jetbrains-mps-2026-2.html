JetBrains 发布 MPS 2026.2：新增 Linux ARM64，投影式智能体工具包显著降耗

JetBrains 今天发布语言工作台 MPS 2026.2，首次提供面向 Linux ARM64 的发行版，构建向导也可生成该架构的独立应用。投影式智能体工具包重做了 MCP 接口，公司称用 Claude Code 搭配 Opus 5 / 5.5 测量时，常见建模与语言定义任务的 token 消耗下降超过 50%。

JetBrains 今天发布语言工作台 MPS 2026.2。官方博客由瓦茨拉夫·佩赫（Vaclav Pech）撰写，页面上的更新时间标记为 2026-11-10 06:39（中欧时间），对应上海时间 13 点 39 分。这是一次正式版本发布，主要内容集中在新的处理器架构支持、构建与打包方式，以及对投影式智能体工具包的改动。

MPS 2026.2 首次提供面向 Linux ARM64（AArch64）的发行版，并搭配相应的 JetBrains Java 运行环境。构建脚本向导现在也可以为基于 MPS 的独立桌面应用（RCP）生成 Linux ARM64 发行包。构建语言新增了从 tar 导入文件、以及「tar 中的文件」这类条目，支持普通 TAR 以及 gzip、bzip2 压缩，来源可以是一个归档文件，也可以是另一套 TAR 布局；导入到 TAR 布局时，符号链接和文件权限会被保留。苹果系统上的归档发行包改用 .tar.gz，不再用 .zip，同样是为了保住符号链接。启动脚本和元数据也改成与当前 IntelliJ 平台一致：引导类路径与 MPS 扩展类路径分开；共用的 --add-opens 参数来自平台元数据；只在对应系统的启动器上带上该系统的软件包。

投影式智能体工具包对 MPS 的 MCP 接口做了大幅度重写。JetBrains 称，公司用 Claude Code 搭配 Opus 5 和 5.5 自行测量，在领域特定语言建模、实现语言定义这类常见任务上，token 消耗下降超过 50%。需要标明的是，这是公司自己的测量，并不是第三方评测，也没有公布完整的测试集或对照条件。新的 MCP 工具可以查询类型系统：理解节点类型和提示信息、比较类型、追踪类型计算，并找出导致错误的那条规则；还可以调用意图动作和快速修复，读取并过滤 MPS 日志，打开、关闭或新建 MPS 项目，以及自动修正已解析 Java 语句里的 SModel 表达式。

界面上也有几处调整。查找用法现在可以按虚拟包分组，而且在「查找用法」里默认打开；向上选择（Ctrl+Up）在列表里会先选中同级节点，作为中间步骤；导入对话框已重做，只会导入当前选中的模型和语言——以前这个对话框会忽略选择。差异对照对话框也有修复，例如窗口缩放时，滚动条上的变更标记会保持在相应位置。编辑器测试现在允许自定义节点匹配函数。

下载与更新说明见 MPS 的「新特性」页面。需要分清的是：Linux ARM64 支持是这次新提供的官方发行方式，构建向导里的对应选项面向基于 MPS 做出的独立应用，并不等于旧项目会自动获得该架构的安装包。token 降耗数字只适用于公司自行测量的那类常见任务，不能直接外推到所有智能体工作流。本条只依据官方博客已经写明的内容，不外推未在上述说明里出现的性能数字或其他平台包。

交叉核对

  • 多方一致：JetBrains 官方博客与 MPS「新特性」页面均记录 MPS 2026.2 发布，首次提供 Linux ARM64 发行版，构建向导也可生成该架构的独立应用；投影式智能体工具包重做了 MCP 接口。
  • 测量口径：token 消耗下降超过 50%，出自公司用 Claude Code 搭配 Opus 5 和 5.5 的自行测量，针对常见建模与语言定义任务；不能当成第三方评测。
  • 待确认：完整测试集、对照条件和是否可在其他模型或任务上复现，官方未另给说明。本条未声称比页面更新时间 13 点 39 分（上海）更精确的发布时间。
