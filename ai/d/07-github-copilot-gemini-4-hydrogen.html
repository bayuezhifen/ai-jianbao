GitHub Copilot 上线 Gemini 4 Hydrogen，覆盖 VS Code 和 JetBrains 等客户端

GitHub 11 月 13 日宣布，谷歌新发布的 Gemini 4 Hydrogen 已在 Copilot 中正式可用，面向 Pro 到 Enterprise 等付费方案，并按供应商目录价格计入用量计费。

2026-11-14 开发者工具

GitHub 在 11 月 13 日的更新说明里宣布，Gemini 4 Hydrogen 已在 GitHub Copilot 中正式推出。说明把它称作谷歌最新的 Flash 型号，定位是更快、更省地完成智能体式编程、工具调用和多步骤工作，并称在遵循指令方面比 Gemini 3.8 Flash 有所改进。Hydrogen 模型本身由谷歌在 11 月 13 日清晨前后发布，昨晨简报已在行业栏写过；本条只记录它进入 Copilot 的这一步，不重复模型发布本身。

可用范围覆盖 Copilot Pro、Pro+、Max、Business 和 Enterprise 用户。模型选择器里可以点到的客户端包括 Visual Studio Code、Visual Studio、Copilot 命令行、Copilot 编程代理、Copilot 应用、github.com、GitHub 移动应用（iOS 和 Android）、JetBrains 系列开发工具、Xcode、Eclipse，以及 Copilot SDK。GitHub 说会分批推送，如果一时还看不到，可以稍后再看。

计费方面，该模型按供应商目录价格纳入按量计费，具体价目要看 Copilot 的模型与定价说明。对企业和商业版，管理员可以在 Copilot 设置的模型策略里管理是否开放 Hydrogen。默认规则是：只要管理员没有关掉全局默认，也没有单独关掉这个模型，新模型会自动启用。

把新模型接到 Copilot，意味着同一套代理工作流里又多了一个可切换的选项，尤其是偏向速度和成本的日常改动。它并不能自动改变仓库权限、代码审查或发布流程，只是把昨天刚发布的型号，接到了已经在用 Copilot 的那些编辑器和命令行里。企业和商业版管理员如果希望先观察再开放，需要检查默认启用策略，避免新模型在无注意的情况下出现在全员的模型列表中。

与此同时，GitHub 同日还有一条关于 Copilot 应用支持 GitHub Enterprise Server 的说明，属于另一项产品进展。本条只写 Hydrogen 的正式上线。截至截稿，GitHub 官方更新说明是最完整的一手来源，第三方转述与说明内容一致，但没有补充新的价格数字或上线比例。

对正在用 Copilot 写代码的人来说，这条更新的实际意义比较直接：模型列表里会多一个更偏向速度的选项，适合日常补全和短程代理任务，但究竟何时出现在自己的编辑器里，还取决于分批推送和所在方案的管理员设置。商务版和企业版如果希望统一模型口径，最好在用户开始切换之前先看一眼策略，而不是等新模型已经出现在全员列表后再补限制。
