英伟达推出面向科学计算的 Vera CPU 机架级平台，德国气候计算中心已选用

英伟达 16 日宣布推出面向高性能计算的 Vera CPU 机架级平台，单柜集成 192 颗处理器，并通过 Quantum-X800 InfiniBand 互联。德国气候计算中心已为 HLRE-5 超算选用 Vera，系统计划 2028 年初投入使用。

2026-11-17 英伟达 / NVIDIA

英伟达 16 日在官方新闻稿中宣布，推出面向高性能计算的 Vera CPU 机架级平台。这是把公司第一款完全自研的数据中心处理器，和英伟达视为高性能计算互连“常规选择”的 Quantum-X800 InfiniBand 放在一起，用来跑气候模拟、分子动力学，以及其他还没有完全转到加速卡上的科学计算和代理式科研负载。这份新闻稿属于 16 日的官方发布，今早 08:20 简报未收入，午报补记，并不把它写成 17 日下午才宣布的消息。

按照官方说明，这一液冷机柜采用英伟达 MGX 设计，把 192 颗 Vera 处理器互联在一起，整柜内存约 300TB、存储约 1PB，官方称合计峰值内存带宽超过 200TB/s。每颗 Vera 配备 88 个自研 Olympus 核心、176 个线程，并使用可更换的 SOCAMM2 LPDDR5X 内存，单处理器内存带宽最高 1.2TB/s。每个 1U 托盘集成 8 颗 Vera 以及 NVMe 存储和管理单元。平台复用 NVL72 机柜的机箱、供电和冷却部件，以便部署和维修。

性能数字目前主要来自英伟达自己的测试，需要把场景写清楚。官方称，在 OpenFOAM 的 motorBike Large 气流模拟中，Vera 的性能约为对比用 x86 系统的 1.9 倍，每瓦性能约为 2.4 倍；在开源的天气研究和预报模式（WRF）上，英伟达给出的预计值是性能提升约 1.6 倍、能效约为对比系统的 2 倍。新闻稿标题里“能效约为 x86 的两倍”是对公司测试的概括，不能理解成所有负载都已经达到这个倍数。

在客户方面，德国气候计算中心（DKRZ）已为 HLRE-5 超算选用 Vera 处理器，同时搭配英伟达 GB200 Grace Blackwell 系统和 Quantum-2 InfiniBand。该系统由 Bull 打造，预计 2028 年初可用，用于气候模拟和人工智能研究，官方称目标是在更低能耗下做全球公里级气候模拟。戴尔科技、惠普企业、联想和超微也将提供完整的 Vera CPU 平台。软件方面，面向 Vera 优化的英伟达 HPC SDK 26.11 已经可以下载；公司还与合作方推出了下一代 Fortran 编译器的公开测试版。

需要分开看的是：这是英伟达把 Vera 从通用人工智能工厂机柜，扩展到以 CPU 为主的科学计算场景，并不等于今天又发布了一款全新的消费级芯片，也不涉及董事会是否请黄仁勋复职。后者今早已有报道，本窗口没有新的董事会决定，也不把请愿签名的小幅变化单独写成一条。
