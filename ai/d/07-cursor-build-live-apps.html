Cursor：云端 Agent 可脚手架并部署「Live Apps」分享链接

Cursor 11 月 5 日 changelog「Build Live Apps in Cursor」：云端 Agent 可搭建应用、按需起 Postgres、用 Cursor SSO 做认证并部署得到分享链接；发布前跑安全检查，付费计划且开启云 Agent 可用。

2026-11-06 Cursor

Cursor 于 2026 年 11 月 5 日在 changelog 发布「Build Live Apps in Cursor」。官方称多数用 Agent 写的工具停在 localhost，现可在 Cursor 里直接做出可分享的线上应用：对云端 Agent 明确说要做应用后，它会脚手架 Web 应用、需要时拉起 Postgres、配置 Cursor SSO 认证并开通托管；若要连内部数仓等系统，会向用户索取密钥。

发布流程：用户选定唯一域名，Cursor 返回线上链接。发布前跑确定性与 Agent 安全检查（如文件里的密钥、暴露凭据），不通过则提示修复，检查通过且用户明确发布后才上线。团队管理员可查看全部应用与密钥、追加审核规则、批准被拦发布或下架应用。分享可按人、组或全员，默认走 Cursor 登录；个人计划也可公开分享。还可签发 Cursor API key 供脚本或机器人调用。

部署源支持 Cursor Origin 与 GitHub 上的新建或已有仓库，GitLab 等其他 Git 提供商「即将支持」。官方举例内部已有活动报名、坐席分配、销售看板、入职培训等应用。该能力面向所有已开通云 Agent 的付费计划。

与 10 月 Agent SDK、远程控制等更新区分：本条是「脚手架 + 数据库 + SSO + 一键托管」的应用发布通道，不是本地 Agent 遥控。细节以 changelog 与文档为准。
