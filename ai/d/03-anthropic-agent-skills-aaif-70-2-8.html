Anthropic 把 Agent Skills 捐赠给 AAIF：超 70 平台接入，约百万技能、近 2.8 亿次安装

继捐赠 MCP 之后，Anthropic 于 10 月 22 日把 Agent Skills 名称、标识、GitHub 组织与 agentskills.io 一并交给 AAIF。官方称已有超 70 个代理平台接入，含 ChatGPT、Cursor、Copilot、VS Code；约 100 万技能发布、近 2.8 亿次安装。

2026-10-22 Claude / Anthropic

Agent Skills 是一套开放格式：一个文件夹里放 SKILL.md 与脚本/参考资料，让代理按需加载领域流程。Anthropic 写明：从 Claude Code 实践起步，2025 年 10 月前后在内部与社区推开，同年 12 月以开放标准发布后，接入面扩到 ChatGPT、Cursor、GitHub Copilot、VS Code 等逾 70 个平台；累计约 100 万技能发布、近 2.8 亿次安装。今日捐赠覆盖名称与标识、GitHub 组织以及 agentskills.io 域名；不加入 AAIF 也可继续使用与贡献。

维护上，Lead Maintainers 为 David Soria Parra 与 Mahesh Murag；工程师以个人身份参与，来自 Anthropic、Google、OpenAI 等。路线图草案包括版本化发布、正式提案流程与编写/安装技能的安全指引。这与同日 AAIF「四项目入驻」新闻互证：Skills 是四件之一，也是 Anthropic 继 MCP 之后又一次把关键栈交给 Linux 基金会中立家园。官方强调：社区对规范往哪走要有发言权，避免单一厂商锁死演进方向。

对开发者的即时含义是治理归属变了，调用方式不必推倒重来——现有技能包与加载器仍可按 agentskills.io 规范继续用。边界：不回炒昨午 Claude Duet 研究预览，也不把「捐赠」写成 Claude 客户端某次功能上线。本条记的是标准与生态规模，不是新模型或新订阅档。

交叉核对

  • 多方一致：捐赠日 10/22；对象 AAIF；名称/logo/GitHub/域名；>70 平台；约 1M 技能、约 280M 安装；Lead Maintainers 两名；此前捐过 MCP。
  • 分歧：平台名单只点名部分头部产品，完整目录未在新闻稿逐一列出。
  • 待确认：版本化发布与安全指引的首个公开里程碑日期。
