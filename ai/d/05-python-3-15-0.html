Python 3.15.0 正式发布：实验性 JIT 提速，UTF-8 默认编码

Python 发布经理 Hugo van Kemenade 于 10 月 9 日宣布 3.15.0 稳定版可用。昨午简报仍将其视为预发布 / RC，本窗改为正式版节点。

2026-10-10 语言 / 运行时 / 框架

Python Insider 博文确认：Python 3.15.0 为最新大版本稳定版，相对 3.14 合并逾五千次提交。官方下载页指向 python.org/downloads/release/python-3150/。Phoronix 同日跟进，聚焦实验性 JIT 在 Linux x86-64 上相对标准解释器约 7%–8% 几何平均提速、在 AArch64 macOS 上相对尾调用解释器约 11%–12% 的表述。

语言与运行时层面的要点包括：PEP 661 引入 sentinel 内置类型；PEP 686 把 UTF-8 定为默认编码；PEP 810 显式惰性导入以加快启动；PEP 814 增加 frozendict；以及理解式解包、包启动配置等。标准库侧有面向剖析工具的整理与高频采样剖析器 Tachyon；类型系统与 C API、默认开启帧指针等也有配套变更。官方 Windows 64 位二进制改用尾调用解释器；macOS 安装包默认带上自由线程支持。

发布说明特别提醒：macOS 27.0 上 IDLE / tkinter 可能在打开部分对话框时挂起，疑与系统行为变化叠加 Tk 工具包有关；依赖 Tk 图形界面的用户可暂缓升级系统或自行验证工作流。该警告不影响「3.15.0 已正式发布」的判断，但属于运维侧需知风险。

与前窗关系：昨午简报明确写「python.org 仍显示预发布 / RC，不写已发布」；本窗以 Insider 正式公告与 Phoronix 交叉核对后改判。Go 安全小版本仍属晨报已收，不重复。
