阿里正式发布通义千问 Qwen4-Max，总参数 2.4 万亿，预览版转为正式上线

通义千问团队 16 日宣布，新一代旗舰模型 Qwen4-Max 正式接入千问 AI 平台。它在 11 日上线的限时预览版基础上转为正式版本，开发者可通过 API 和 Token Plan 调用。

2026-11-16 行业

阿里通义千问团队 16 日宣布，新一代旗舰模型 Qwen4-Max 正式上线。阿里云百炼的模型上架记录把“qwen4-max”列入当天更新，千问 AI 平台的模型页同步挂出该型号。IT之家、品玩和日本科技媒体 GIGAZINE 都在同一天转述了这次发布。需要把它和五天前的预览分开：11 月 11 日上线的是 Qwen4-Max-Preview，当时只走 Token Plan，预览期原定到 11 月 25 日结束；今天这笔更新的含义，是正式版本接入平台，开发者可以用 API 调用，而不只是限时试用。

官方和多家报道给出的模型规格一致：采用混合专家架构，总参数 2.4 万亿，每个 token 激活 71B 参数，原生支持图像和视频理解，上下文窗口为 100 万 token。品玩还写到，每个 token 的激活参数较上代减少约 25%。千问 AI 平台标价为每百万 token 输入 10 元、输出 30 元，缓存命中 0.5 元。IT之家在引用官方博客时补充，模型面向办公、创作、软件开发和科研等场景，并介绍了 Gated DeltaNet、稀疏注意力、门控残差和 N-gram Embedding 等架构取舍；这些属于官方技术说明，不是第三方复现结论。

效能数字目前主要来自官方和官方引用的评测。IT之家转述，Qwen4-Max 在团队自建的 Work360 基准上得到 52.69 分，前代 Qwen3.8-Max 为 47.74 分；同等性能下，Xhigh 和 High 两档推理强度的 token 消耗分别减少约 24% 和 35%，Terminal-Bench 4.0 上的降幅约 48% 和 49%。官方还称，Work360 评测中单个任务的平均费用从 26.58 元降到 11.16 元，降幅约 58%。品玩写到，在 CodeArena 前端编程盲测中，Qwen4-Max 位列第六，位置在 GPT6-Astra 和 Claude Fable 5.1 之间；在 Agents' Last Exam 上得到 46.7 分，较上代高 18.8 分。这些分数都应以“官方或评测组织公布的数字”来理解，本报没有独立跑分。

发布材料还强调长程任务和边做边改的交付方式。官方称模型内置 Live Delivery 机制，先交出可用的第一版，再按反馈逐版扩充，并开源了相应插件。展示案例覆盖三维建模、游戏引擎、产线与零件编程，以及金融、法律和临床辅助等场景。其中汽车零件加工一例称，单个工件编程的人工投入从约 475 分钟降到 24 分钟，这是官方给出的案例数字，尚未看到使用方的独立说明。官方同时表示，Qwen4 系列中的小尺寸模型将陆续开源。目前 API 已在 QwenCloud 上线，用户也可通过千问办公、Qoder 和千问应用直接使用。

交叉核对

  • 一致处：阿里云百炼 16 日上架记录、千问 AI 平台模型页，与 IT之家、品玩、GIGAZINE 均确认当天正式发布 Qwen4-Max；总参数 2.4 万亿、百万 token 上下文、原生视觉能力，以及预览版已于 11 日先行上线，几家报道口径一致。品玩明确写出激活参数 71B，与 IT之家对官方博客的转述相符。
  • 官方标价：千问 AI 平台模型页列出输入 10 元、输出 30 元、缓存命中 0.5 元（每百万 token）。品玩强调“缓存命中每百万 Tokens 低至 0.5 元”，与标价页一致，不能把缓存命中价写成普通输入价。
  • 评测与案例：Work360、Terminal-Bench、CodeArena、ALE 以及零件编程用时等数字，均来自官方或官方引用，本报未复现。Work360 是通义千问团队自建框架，不宜写成已经广泛通行的行业标准。
  • 待确认：正式版与预览版在权重和能力上的具体差异、小尺寸开源模型的时间表，以及第三方能否复现官方给出的费用降幅。
