Grok / xAI

马斯克称 Grok 4.8「不会令人失望」；再核仍 4.7、无 4.8 上线、未取消 4.7

埃隆·马斯克 10 月 30 日在 X 回复称，尽管耗时超出预期，Grok 4.8「不会令人失望」，并强调不为刷榜优化、更看重实用。同日核对 docs.x.ai：旗舰仍推荐 grok-4.7，未见 grok-4.8 型号，亦未见取消 4.7。

2026-10-30 Grok / xAI

马斯克帖文原文大意是：知道拖得比预期久，但 Grok 4.8 不会令人失望；不为基准测试优化，也不在意榜单分数，但会非常有用。时间戳约 2026-10-30 05:17 UTC（上海约中午 13:17）。这是对本窗版本阶梯最直接的第一手口径：承认 4.8 仍在路上，同时没有说「4.8 取代并下架 4.7」，也没有宣布即日可调。

官方开发者文档与模型价目页仍把 Grok 4.7 freer 为代码与通用任务首选：模型名 `grok-4.7`，上下文 50 万 token，并单列 Fast 变体仅在 Cursor / Grok Build 计费。价目表可见 4.7 / 4.6 / 4.5 / 4.3 等，没有 `grok-4.8` 行。因此：现网旗舰仍是 4.7；4.8 属马斯克预告中的下一档；没有证据表明 xAI 已取消 4.7。

同日稍早，马斯克还转发并喊话「Hire Grok @Bot to be an employee」，继续推 Bot 产品叙事；另有「Bot 无免费档」等运营口径。这些与模型版本号是两条线：Bot 是代理产品，4.7/4.8 是底层文本模型阶梯。媒体若写「4.8 已取代 4.7」，与马斯克用词及文档现状都不符。

交叉核对

  • 多方一致：马斯克 X 原帖点名 Grok 4.8；docs.x.ai models / pricing 仍列并推荐 grok-4.7；未见 4.8 API 名。
  • 分歧：外围讨论常把「即将发布」写成「已取代」；马斯克只说「不会失望 / 会很有用」，未给日期，也未说下架 4.7。
  • 待确认：4.8 公开 API 日；4.7 是否在 4.8 GA 后降为别名或并行保留。
