OpenAI 推出 Grid Protectors：佐治亚试点电网需求响应至多约 1000MW

11 月 2 日 OpenAI 发布全国性「Grid Protectors」计划，承诺未来算力园区在电网吃紧时可下调用电；佐治亚 Effingham 项目与 Georgia Power 约定至多约 1000MW 灵活需求响应。

2026-11-02 OpenAI

OpenAI 于 2026 年 11 月 2 日在官网推出 Grid Protectors Program，定位为面向未来「算力园区」（compute campus）的全国性安排：与公用事业、监管与政策方协作，在电网承压时主动削减园区用电，必要时再用场内发电或储能平滑负荷。官方把美国数据中心容量「2030 年前或超 100GW」的预期写成背景，强调大负荷用户应自付电费与配套基建成本，避免把峰值扩容成本转嫁给居民与小企业。

试点落在佐治亚州 Effingham 县规划园区。公司称已承诺承担为服务该项目所需的全部基础设施与供电成本；与 Georgia Power 的协议还包括至多约 1000 兆瓦的灵活需求响应——官方折算约相当于约 70 万户家庭的平均用电需求，并称极端高温时可把电力留给空调负荷。园区仍在建设期，但 OpenAI 打算把这套安排当作 Grid Protectors 的样板，并称 Georgia Power 预计其大负荷协议组合自 2029 年起可为客户带来约 9.5 亿美元年化节省（含 Project Camellia 等），典型居民用户每月或可少付至少约 15 美元（按月用电约 1000 千瓦时估算）。

The Verge 同日报道把这条放进更广的舆情里：多地反对数据中心扩建，田纳西、佛罗里达、俄克拉荷马、俄勒冈等州已立法限制把能源成本转嫁居民；OpenAI 改称「算力园区」、强调「可被电网调用的资源」，也被读作公关与政策前置。文中亦提到公司与 Oracle、软银合作的 Stargate 等其他州项目。官方则强调灵活性不能替代新建电源与输电，而只是与投资并行的削峰手段。

对读者而言，关键数字是「至多约 1000MW」与「仍在开发的试点」，不是已经每天在调的现货容量。实际可下调多快、持续多久、违约与补偿怎么写进购电/互联协议，要等各州公用事业委员会文件与后续承诺披露。把它当成 OpenAI 在用电政治与电价争议升温时的制度性表态即可，不宜直接外推到所有 Stargate 站点已同等签约。

交叉核对

  • 多方一致：11-02 官网发布 Grid Protectors；佐治亚 Effingham 试点；与 Georgia Power 至多约 1000MW 需求响应；约 70 万户量级表述；强调自付基建与电费。
  • 分歧：The Verge 更突出反对数据中心的舆情与「改名算力园区」的叙事；官方长文更强调削峰、固定成本分摊与 2029 年客户节省测算。
  • 待确认：各州后续签约细节、实际可调用容量与响应时限、Stargate 其他站点是否复用同模板，以公用事业备案与 OpenAI 后续披露为准。
