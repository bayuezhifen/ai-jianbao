OpenAI 推出 GPT-6.2 Astra 与 Sol，面向专业工作与日常任务，并下调 Astra 的 API 价格

OpenAI 17 日发布 GPT-6.2 Astra 和 GPT-6.2 Sol。前者面向高难度专业项目，后者面向日常工作；两者即日起在 ChatGPT Work、Codex 和 API 中提供，Astra 的 API 单价较上代下调。

2026-11-18 OpenAI

OpenAI 17 日在官网发布 GPT-6.2 Astra 和 GPT-6.2 Sol。产品更新列表把两条都标为当天的产品新闻。官方的分工很明确：Astra 面向“最难的那些专业项目”，Sol 面向日常工作。公司称，两个模型都尽量用更少的输出 token 完成更难的任务，从而在用量限额内多做一些事情。对开发者而言，Astra 在 API 中的输入和输出价格较 GPT-6 Astra 下调 20%，缓存输入再打六折，官方给出的标价是每百万 token 输入 8 美元、缓存输入 0.40 美元、输出 40 美元；Sol 的 API 价格则仍与 GPT-6.1 Sol 相同。

在可用性上，官方写明：即日起，ChatGPT 的 Plus、Pro、Enterprise 和 Edu 用户可在 ChatGPT Work 和 Codex 中使用这两个模型。订阅 Pro 500 的用户可以在两个模型上使用 Ultrafast；Pro 200 的用户则是第一次获得 Ultrafast，先从 Sol 开始。企业与教育工作区需要管理员开启后，符合条件的用户才能用上。开发者可通过 API 调用 gpt-6.2-astra 和 gpt-6.2-sol，两个模型在发布时都提供 Ultrafast。Axios 在报道微软自研模型时，也确认 OpenAI 于周二发布了这对模型，并提到 Astra 较上代降价 20%。

官方用多组内部或合作评测来说明“专业输出”的变化。例如，在考察多步骤专业工作的 Agents’ Last Exam 上，公司称 Astra 比 GPT-6 Astra 高 5.2 分，成本不到三分之一，并比 Claude Fable 5.2 高 5.5 分、成本约为后者的 5%；在 Terminal-Bench-Science 和 Vals Science Index 上，Astra 也被写成新的领先成绩。Sol 在 Cognition 的 FrontierCode 2.0 上与 Astra 相差约 0.5 分，成本约为五分之一；在 OpenAI 自己的 LifeVal 日常任务评测上，Sol 的成绩高于 GPT-6 Astra，成本约为七分之一。这些都是厂商选定的基准和成本算法，适合用来理解官方想强调的方向，而不能单独当作排行榜定论。文中还提到，面向律师的 Astra for Law 是建立在 GPT-6.2 Astra 上的配置，并在法律文书评测 Harvey LAB-AA 上给出更高分数；同日另有 ChatGPT for Sales，本报不将其展开成第二条，以免把模型发布写成套件汇总。

安全方面，官方称此次部署配有迄今最严的防护，并写明两个模型都达到其准备框架下生物和化学能力的“高”阈值，Astra 还是首个对外发布、达到“人工智能自我改进”高阈值的模型。公司把这一档解释为：相当于给每位研究人员配上一名很强的研究工程师助手（相对 2024 年的基线）。更细的测试与限制写在同日发布的系统卡里。对这类自评，报道只转述官方定义，不把它写成已经出现自我改进的系统。

交叉核对

  • 一致处：发布日期、两个型号的定位、ChatGPT Work / Codex / API 的开放范围，以及 Astra API 降价 20%、缓存输入六折的标价，均可在 OpenAI 官网核到；Axios 对周二发布和 Astra 降价的转述与官网相符。
  • 口径：各项基准领先幅度和“成本只有几分之一”均来自官方选定的评测和计价方式，须保留厂商口径；系统卡中的能力阈值是公司自己的准备框架，不是监管认定。
  • 同日但未单独成条：ChatGPT for Sales、Astra for Law 向企业客户开放申请，只在正文中略作交代。
