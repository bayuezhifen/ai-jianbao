英伟达与 Oracle：Vera Rubin NVL72 与 Vera CPU 在 OCI 正式可用，Supercluster 规划多吉瓦

在 Oracle AI World，英伟达与 Oracle 宣布 Vera Rubin NVL72 与 Vera CPU 在 OCI 正式可用，并计划把 Supercluster 扩到多吉瓦级；另规划 HGX Rubin NVL8。

2026-10-28 英伟达 / NVIDIA

英伟达新闻稿与 Oracle 同日通稿写明：OCI Supercluster 计划引入 Vera Rubin NVL72，规模瞄向多吉瓦，服务训练、推理与智能体负载；Vera Rubin NVL72 与 Vera CPU 已在 OCI 正式可用。叙事重点是「GPU 吃重训练/服务，CPU 吃重工具调用、跑代码、取数」——客户可把 CPU 与 GPU 资源分开扩缩，减少智能体步骤之间 GPU 空转。

技术栈摘要：NVL72 机柜经 NVLink 互联 72 块 GPU；网络侧提到 Oracle Acceleron 与 Spectrum-X（含 Spectrum-6 交换机）以及 BlueField-4 DPU。平台还将引入 HGX Rubin NVL8：八块 Rubin GPU 的 x86 服务器形态，稿中写配备两颗 64 核 Intel Xeon 6、4TB DDR5 与 6.4 Tbps 级高速 RDMA。OpenAI 工程负责人引语称 Abilene 已有超过 10 万块 Blackwell 的 OCI Supercluster 训练并服务 GPT-6 Astra；另有引语称 Vera CPU 正进入生产，支撑智能体沙箱类负载。

与今晨关系：不回炒上周 OpenShell 参考架构；本窗是 Rubin/Vera 在 OCI 的可用性与扩容规划。公开云容量本身不单开云厂商栏，但英伟达硬件产品与机柜形态归英伟达栏。

边界：多吉瓦为规划表述；HGX Rubin NVL8 为「计划引入」。客户名单除引语中的 OpenAI 外，勿擅自扩写未具名大客户。

交叉核对

  • 多方一致：NVIDIA Newsroom 与 Oracle 通稿均确认 NVL72/Vera CPU GA、多吉瓦扩容规划、HGX Rubin NVL8 计划。
  • 分歧/二手：OpenAI 引语中的 GPU 规模与 Astra 部署为合作方表述，非第三方审计。
  • 待确认：多吉瓦落地节奏、NVL8 公开定价与区域可用性。
