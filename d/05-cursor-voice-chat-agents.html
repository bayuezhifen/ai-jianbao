Cursor

Cursor：与智能体实时语音通话，由 Grok Voice 驱动

11-06 changelog：Agents 窗口、IDE、网页与 iOS 均可双向语音；编码智能体边做边播报进度。开启 Privacy Mode 时语音零留存。

2026-11-07 Cursor

Cursor 于 11 月 6 日在 changelog 发布「Voice Chat with Agents」：开发者可以和编码智能体打实时双向语音电话——口头描述改动、询问正在做什么、边听进度边继续下指令。功能覆盖 Agents 窗口、桌面 IDE、网页端以及 Cursor for iOS。

当智能体空闲且输入框为空时，可点波形按钮「Start voice chat」开通话。iOS 还支持「Hey Siri, call Cursor」拉起新智能体通话，并在锁屏 Live Activity 上静音或挂断。语音智能体负责听、答并把任务交给当前聊天里的编码智能体；后者会在执行中播报短进度，结束后给简要结论，通常不必把整段文字回复念完。

通话中可只读查询 diff、运行状态、与该智能体的历史消息与通话，或在含多名工作者的 Project 里切换对象，而不打断正在跑的编码任务。语音由 Grok Voice 负责识别与合成，设置里可选 Ara、Eve、Leo、Rex、Sal 等音色；编码模型仍用用户当前所选。开启 Privacy Mode 时，官方称语音聊天零数据留存。它与早先把语音转成输入框文字的听写（曾称 Voice Mode）是两套能力。

IT之家 11 月 7 日跟进，并提到通话有每日上限，长时间沉默且无任务时约 10 分钟会自动结束。本条不回炒晨报 Live Apps 托管部署。

交叉核对

  • 多方一致：Cursor 官方 changelog 与 IT之家在入口、平台覆盖、Grok Voice、Privacy Mode 零留存等要点一致。
  • 区分：听写仍是语音转文字；Voice Chat 是双向语音对话。
  • 待确认：各套餐每日通话额度以产品内提示与文档为准。
