微软在 Ignite 发布 MAI Code 2、Cyber 2 Flash 等七款自研模型，强调更低成本的企业级能力

微软人工智能部门 17 日宣布推出一组自研模型，覆盖编程、网络安全、图像、实时语音和决策等场景，并把价格表现作为主要卖点，编程模型已进入 GitHub Copilot。

2026-11-18 行业

微软人工智能部门 17 日在 Ignite 会议期间发表综述稿，宣布一次性推出七款自研模型，并把“能在可接受价格下整天跑智能体”作为主要卖点。名单包括：面向安全防御的 MAI Cyber 2 Flash，面向日常企业编程的 MAI Code 2 和更轻量的 Code 2 Flash，图像编辑模型 MAI Image 2.7，实时语音模型 MAI Realtime 1，基于 MAI Transcribe 2 的 Dragon Copilot Transcribe，以及决策模型 Decision 1.1。文中还提到，第二代加速器 Maia 200 已投入生产，用于运行公司最大的模型。这些是微软自己的产品宣布，不是对 OpenAI 或 Anthropic 模型的转授权说明。

编程模型的介绍更集中。微软在同一天的专稿里说，MAI Code 2 针对把代码送进生产环境、深度调试、跨文件实现和仓库级推理等“每天都会遇到”的企业编程任务，并明确它还没有针对基础科学或超长程智能体工作做专门调优。官方给出的对比是：在 DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas 和 FrontierCode v1.1 四组基准的平均值上，Code 2 达到 GPT-6.1 Sol 约 98% 的水平，价格约为后者的 40%；达到 Claude Opus 5.5 约 96% 的水平，价格约为后者的 5%。Code 2 Flash 则对准解释代码、小范围修改和反复迭代，官方称其表现接近 GPT-6 Luna 和 Claude Haiku 5.5，价格分别约为两者的 65% 和 20%。这些数字都是厂商自己的基准口径，需要连同参照模型一起读，不宜直接当成第三方评测结论。

落地渠道方面，官方写明 Code 2 和 Code 2 Flash 已进入 GitHub Copilot，Code 2 Flash 还在 Microsoft Foundry 做有限预览，并计划登陆更多开发者平台。综述稿还说，网络安全模型被设计用来在生产系统上昼夜运行监测和修补，并提到前代 MAI Cyber 已在微软安全产品（文中称为 MDASH）的扫描中占到相当比例。新版安全模型的具体开放范围，官方综述着墨不多，本报不以二手时间表补写上市日期。

Axios 17 日的报道把这组发布概括为：微软要以更便宜的专用模型，去和 OpenAI、Anthropic 竞争，并可能改写自己与外部模型供应商的关系。稿件也写到，OpenAI 同一天发布了 GPT-6.2 Astra 与 Sol。微软人工智能负责人 Mustafa Suleyman 在采访中表示，公司仍在推进可更广泛竞争的通用前沿模型，但没有给出时间表。把微软的模型发布和 OpenAI 的新模型放在同一窗口里看，竞争焦点已经从“有没有自研模型”转向“在哪些日常任务上能把价格打下来”。

交叉核对

  • 一致处：七款模型名单、Code 2 / Code 2 Flash 进入 GitHub Copilot、官方给出的价格与基准对比，均可在微软人工智能官网 17 日两篇稿件中核对；Axios 对发布意图的概括与官方“价格性能”叙述方向一致。
  • 口径：各项“达到某某模型百分之几、只要其价格的几分之几”均来自微软自有基准，报道中保留厂商口径，不改写成第三方评测。
  • 待确认：Cyber 2 Flash 在安全产品中的具体供货时间与客户范围；通用前沿模型的发布时间；Code 2 进入 Copilot 后，实际会替换多少外部模型调用。
