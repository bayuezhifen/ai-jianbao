群晖 / Synology

群晖发布 SA-26:19（严重）与 SA-26:18，修复 DSM 未授权 SQL 注入等漏洞，须升级

昨天下午 17:06（上海）同时公布两份通告。SA-26:19 含一枚 CVSS 9.8、无需登录的 Auth API SQL 注入，影响 DSM 7.2.1 至 7.4，须升到公告给出的补丁版本；SA-26:18 另列 25 个漏洞，主要覆盖 7.3 和 7.4。官方没有提供缓解措施，也没有说已经出现在野利用。

2026-11-10 群晖 / Synology

群晖在 11 月 10 日下午几乎同时公布了两份针对 DSM 的安全通告。英文和中文站点都写明，SA-26:19 的发布时间为当天 17:06:42（上海），严重程度为「严重」，状态为已解决，目前是第 1 版，也就是首次对外公布；官方在缓解措施一栏写的是「无」。同一分钟稍早，17:06:33，还发布了重要性为「重要」的 SA-26:18。法国国家网络安全局下属的 CERT-FR 当天发出 CERTFR-2026-AVI-1493，把两份通告一并概述，合计 27 个漏洞编号，受影响版本与官方表格一致。需要说清楚的是：官方和 CERT-FR 都没有写这些漏洞已经出现在野利用，不能据此写成大规模爆发。两份通告修的是 DSM 系统本身的问题，和本周早些时候围绕第三方套件的通告不是同一回事。

SA-26:19 里最要紧的是 CVE-2026-76954。官方将其标为严重，CVSS 3.1 分为 9.8，类型是 SQL 注入，出在 DSM 的认证接口（Auth API）。通告的意思是：在列出的补丁版本之前，远程攻击者可利用这处对 SQL 命令中特殊元素处理不当的问题，读取或写入任意文件，并实施拒绝服务。该条攻击从网络即可发起，复杂度低，不需要登录，也不需要使用者再点一次确认。同份通告还有 CVE-2026-85101，标为重要，CVSS 3.1 分为 8.6，属于通过另一条路径或通道绕过认证，出现在 rsync 相关实现里。官方描述是：远程攻击者可以读取特定文件、写入任意文件，并实施有限度的拒绝服务。群晖致谢了越南 Viettel 网络安全研究实验室的 Nguyễn Bá Nam Dũng、Hà Thế Long，以及 Warisse Valentin（Aytio）。

还在使用受影响 DSM 的设备，升级目标应严格对照官方表格。SA-26:19 把 7.2.1 到 7.4 都标为严重：DSM 7.4 须升到 7.4.1-90080-1 或更高；DSM 7.3 须升到 7.3.2-86009-5 或更高；DSM 7.2.2 须升到 7.2.2-72806-10 或更高；DSM 7.2.1 须升到 7.2.1-69057-13 或更高。中文用户可以直接看 synology.cn 上的通告。SA-26:18 另列 25 个漏洞，产品表只覆盖 DSM 7.4 和 7.3，升级目标同样分别是 7.4.1-90080-1 或更高、7.3.2-86009-5 或更高；7.2.x 并未出现在这份通告的产品表里，这一点与 SA-26:19 不同，两份名单不能混着看。

在 SA-26:18 分数较高的条目中，官方细节包括：CVE-2026-13672（8.8 分，SSOAuth 越权，需要已登录用户）、CVE-2026-18792（8.8 分，Sharing API 路径遍历，需要已登录）、CVE-2026-74857（8.8 分，Auth API 缺少关键认证步骤，需要已登录）、CVE-2026-18596（8.1 分，一次性密码认证绕过，官方写的是持有有效用户凭据的远程攻击者）、CVE-2026-19048（8.1 分，缩略图链接解析）、CVE-2026-81584（8.1 分，User API 的 SQL 注入，前提是能够控制已被攻陷的 LDAP 或 AD）、CVE-2026-18633（7.5 分，nfsd 未初始化指针导致远程拒绝服务，且无需登录）、CVE-2026-75785（7.2 分，VPN API 命令注入，需要管理员权限）。其余多为中等，大致在 4.3 到 6.8 分之间，涉及 SNMP、WebDAV、媒体解析、支持表单的证书校验、跨站脚本、Security Advisor 授权错误、服务端请求伪造、任务计划等。完整清单应以官方通告或 CERT-FR 公告为准。

因为官方没有给出补丁之外的缓解办法，能做的就是尽快升到上述版本，并在升级后确认服务与备份仍正常。若设备暂时无法升级，自行收紧管理面暴露范围并不能代替补丁，也不是官方给出的正式缓解措施。

交叉核对

  • 多方一致：群晖中英文通告与 CERT-FR 的 CERTFR-2026-AVI-1493 均确认两份通告于 11 月 10 日下午发布；SA-26:19 为严重、已解决、第 1 版，无缓解措施；补丁版本号与受影响产品表一致；两份通告合计 27 个漏洞编号（2 个加 25 个）。各方均未声称这些漏洞已出现在野利用。
  • 范围差异：SA-26:19 覆盖 DSM 7.2.1 至 7.4；SA-26:18 的产品表只列出 DSM 7.3 与 7.4，不含 7.2.x。两份通告不能当成同一张升级名单。
  • 待确认：是否已有在野利用，官方与 CERT-FR 均未表态；SA-26:18 其余中等漏洞的完整编号与评分，本条未逐一罗列，应以官方通告或 CERT-FR 公告为准。
