开源治理与许可证

腾讯混元宣布 Hy4 正式开源，官方许可证是「腾讯 Hy 许可证」而非 Apache 2.0

混元团队今天把 Hy4 的模型权重放到 Hugging Face、ModelScope 和 GitCode 等平台，并同步放出 FP8 和预训练基座。官方许可证在 Apache 2.0 基础上加了大规模「模型即服务」商用条款，并明确写明这不是 Apache 2.0。

2026-11-20 开源治理与许可证

IT之家今天中午报道，腾讯混元团队宣布 Hy4 大模型正式开源，权重已在 GitHub、Hugging Face、ModelScope 和 GitCode 上线，开发者可以自行下载部署。Hugging Face 上的模型卡也写明，此次开放的是 Hy4、Hy4-FP8 以及预训练基座模型。Hy4 正式版最早在 11 月 4 日发布，当时官方说权重将于近期开源；今天落地的，是此前预告过的权重，而不是又发布了一个新的主版本。

按照 Hugging Face 模型卡，Hy4 是混合专家架构，语言主干总参数约 7700 亿，每个 token 激活约 490 亿参数，上下文长度为 100 万 token（1,048,576）。主干有 78 层，其中第一层是稠密前馈网络，其余 77 层是专家层；每个专家层有 256 个路由专家和 1 个共享专家，每个 token 会激活 8 个路由专家加上共享专家。模型还带视觉编码器，支持图像和视频理解，并内置用于推测解码的 DFly2 草稿模块。IT之家写，至此混元大语言模型系列已全部开放，覆盖 Hy3 preview、Hy3、Hy4 preview、Hy4 以及 Hy4 flash 等版本。需要分开看的是：今天的主条是旗舰版 Hy4 权重开放，并不等于上述每一个历史版本都在今天才第一次出现。

许可证是这条新闻里最容易写错的地方。IT之家写「Hy4 及 Hy4 preview 采用 Apache 2.0 许可证，允许商业使用与修改」。本报核对其官方许可证原文后，不能沿用这一说法。Hugging Face 上 tencent/Hy4 的 LICENSE 文件标题是「Tencent Hy License, Version 1.0」，并在开头写明：这份许可证派生自 Apache License 2.0，主要改动是第 10 条针对大规模「模型即服务」（MaaS）业务的额外商用条款；它不是 Apache License 2.0，也不由阿帕奇软件基金会背书。第 10 条规定，若把模型或衍生作品用于向第三方提供远程推理或微调等 MaaS 业务，并且出现下面任一情形，就必须另行取得腾讯书面授权：连续 12 个月全球总收入超过 5000 万美元；或者相关产品或服务在任一公历月的月活跃用户超过 1 亿。仅供内部使用、且不向第三方提供模型、衍生作品或其输出的，不适用这一条。许可证文本把微调和量化等改动也算进衍生作品。

IT之家还转述官方说明称，训练数据只纳入了概念验证生成、漏洞修复等防守性网络安全内容，并去掉了漏洞利用、逆向和渗透等攻击性数据；腾讯玄武实验室与科恩实验室的审计未发现明显的进攻性能力风险。这些评估细节写在官方的模型安全评估卡片里，本报未逐页复核该 PDF，只作为对官方说明的转述记下。对使用者来说，权重可以下载，并不等于可以按 Apache 2.0 的口径去做大规模对外的模型服务；是否触及相关门槛，要看官方许可证第 10 条，而不是媒体稿里的简称。

交叉核对

  • 一致处：IT之家与 Hugging Face 模型卡都确认，Hy4 权重已开放，并同时提供 FP8 和预训练基座；总参数约 7700 亿、激活约 490 亿、上下文 100 万 token，与模型卡规格一致。
  • 分歧：IT之家写 Hy4 及 Hy4 preview 采用 Apache 2.0。官方 LICENSE 明确是「腾讯 Hy 许可证」第 1.0 版，派生自 Apache 2.0 但不是 Apache 2.0，并含大规模 MaaS 商用限制。本文以官方文本为准。
  • GitHub：IT之家把 GitHub 列为同步上线平台之一；本报打开的 Hugging Face 模型卡主要列举 Hugging Face、ModelScope 和 GitCode。仓库 Tencent-Hunyuan/Hy4 存在，但权重发布以模型托管平台上的 LICENSE 和模型卡为准。
  • 待确认：Hy4 preview、Hy4 flash 是否与正式版使用同一份「腾讯 Hy 许可证」，需分别查看各仓库许可证，本文只对正式版 Hy4 的官方 LICENSE 作了核对。
