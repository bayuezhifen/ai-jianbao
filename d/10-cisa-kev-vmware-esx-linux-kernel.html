漏洞与勒索

CISA 将 VMware ESX 与 Linux 内核两漏洞列入已知在野利用目录

CISA 于 10 月 28 日把 CVE-2026-41709（Broadcom VMware ESX 日志不足）与 CVE-2026-46300（Linux 内核变量未初始化）加入 KEV。联邦民用机构须按 BOD 26-04 对公开暴露资产优先处置。

2026-10-29 漏洞与勒索

CISA 警报写明：两漏洞均有活跃利用证据。CVE-2026-41709 指向 Broadcom VMware ESX 的日志不足问题，可能削弱取证与告警；CVE-2026-46300 为 Linux 内核缺失变量初始化。KEV 目录要求联邦民用行政分支按约束性运营指令 BOD 26-04，对「利用后可完全控制资产」的高风险项加快修补，并在补丁前评估是否已被入侵。

公开二次报道中，BleepingComputer 等近期还跟踪过其他在野链（含与 PHP webshell 相关的组合利用讨论）；本窗主条以 CISA 10-28 警报列出的两枚 CVE 为准，不把更早 Magento KEV（昨晨已收）再炒一遍。勒索软件字段在部分汇总表中仍标 Unknown，不等于「已确认大规模勒索活动」，但也不排除后续改判。

对运营方：虚拟化集群与 Linux 服务器资产应对照厂商公告与发行版安全公告，确认补丁或缓解；ESX 日志类问题还要检查是否影响既有 SIEM 取证假设。CISA 鼓励所有组织按 KEV 做风险排序，而不仅是联邦机构。

边界：列入 KEV = 有在野利用证据 + 有缓解指导，不自动等于「全网爆发勒索」。具体 CVSS、利用前提与补丁包以 NVD/厂商公告为准。

交叉核对

  • 多方一致：CISA 10-28 警报两 CVE；KEV + BOD 26-04 框架。
  • 分歧：二级媒体对 Linux 洞「可与 webshell 链」的细节深度不一，本简报以警报点名为准。
  • 待确认：联邦修复截止日期字段、勒索活动是否改判 Known、厂商补丁全面覆盖发行版列表。
