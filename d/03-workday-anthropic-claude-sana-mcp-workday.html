Claude / Anthropic

Workday 与 Anthropic 合作：Claude 与 Sana 经 MCP 互通，权限仍走 Workday 规则

Workday Rising 2026 上双方宣布：人可在 Claude 或 Sana 任一入口开工，任务与上下文经 Model Context Protocol 往返，审批与可见范围仍按客户在 Workday 里已有的权限与审计控制。

2026-10-14 Claude / Anthropic

Workday 于 2026-10-13（拉斯维加斯 Rising）与 Anthropic 联合发稿：把 Claude 的推理能力接到 Workday 的 Sana 智能体编排层，以及 HR/财务域数据与业务规则。官方强调两条路径——在 Sana 里跑长流程（薪酬周期、结账等），需要推理时再调用 Claude 并只传该步所需上下文；或在 Claude 里直接唤起 Sana 智能体，查看编制/预算、处理发票例外，但「每一步仍服从客户既有权限与审计」，Claude 只展示该用户有权看见的内容。

技术胶水写明为开源标准 Model Context Protocol（MCP）。联名客户还可在 Claude 侧用 Workday Agent-Ready Tools 自建智能体，权限模型不另起炉灶。可用性：Sana in Claude 插件已对早鸟客户开放，预计 2026 年末前后正式；Agent-Ready Tools 已通过 Workday Extend AI 对全体客户正式可用。双方互为客户的叙事也写进稿：Anthropic 财务与人事跑在 Workday 上，Workday 工程与市场侧使用 Claude Enterprise / Claude Code。

本条是企业集成与产品通道，不是新模型版本。昨午已收录的蒸馏防护（自报推理数据被偷学下降约 90%–99%）属安全研究帖，晨报不回炒。媒体侧 PR Newswire 与 Workday 新闻室稿件一致；目前未见 Anthropic 官网独立长文覆盖同一合作，交叉核对以 Workday 官方稿 + 通讯社转发为准。

对采购与安全团队：重点看 MCP 连接的数据驻留（稿称复杂流程数据留在 Workday 内）、审批是否必须人工确认，以及插件 GA 时间表是否滑动。

交叉核对

  • 一致：Rising 当日发布、MCP、双入口、早鸟插件、Agent-Ready Tools 已 GA。
  • 边界：非新 Claude 模型；蒸馏防护昨午已收。
  • 待确认：正式 GA 具体周次、各区域合规附录。
