百度开源文心 ERNIE 5.5 Flash Base：总参 280B、每 token 激活 14B

百度于 11 月 5 日发布预训练终点 Base 权重：稀疏 MoE、训练上下文最长 128K、微调/推理支持 1M；提供 FP8 与 BF16，挂 Hugging Face。

2026-11-06 行业

百度文心团队在官网发布页写明：ERNIE-5.5-Flash-Base 是稀疏 MoE 语言模型，总参数 280B、每 token 激活约 14B，在约 33.5T tokens 上从零完成预训练；最长训练上下文 128K，微调与推理支持 1M tokens。本次放出的是预训练终点 checkpoint，未经中训练与后训练，供社区自行做领域适配、指令微调与强化学习等后续训练。

结构侧强调效率：混合稀疏注意力（多数层用重度压缩注意力 HCA，少数层 MLA+稀疏注意力）、Multi-Router Latent MoE、流形约束超连接 mHC、MultiMax 输出头，以及用 ECHO 取代传统 MTP 模块等。分词器为约 20 万词表的新 BPE，数字按从右到左最多三位一组切分。

评测页在同一框架下与 DeepSeek-V4-Flash-Base、Hy3-preview-Base、MiMo-V2.5-Base 等同级 Base 对比，称在推理、代码与多项综合/长上下文基准上表现靠前。权重以 ERNIE 5.5 Flash Base Model License Agreement v1.0 在 Hugging Face 提供 FP8 与 BF16 safetensors；文档提示 Base 输入需以 BOS 开头，并可通过 SGLang/vLLM 的 completions 接口部署。官方称经过后训练的 ERNIE 5.5 Flash 将随后推出。

IT之家、第一财经等国内媒体同日跟进，核心数字与「预训练终点、未后训练」口径与官网一致。本条只报道开源基座发布，不外推未公开的后训练产品时间表。

交叉核对

  • 多方一致：官网与 Hugging Face 均确认 280B/激活 14B、预训练终点、FP8/BF16、128K 训练与 1M 推理上下文。
  • 待确认：后训练版 Flash 的发布时间与许可细节以官方后续公告为准。
