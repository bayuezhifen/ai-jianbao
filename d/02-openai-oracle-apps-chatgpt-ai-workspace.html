OpenAI 扩大与 Oracle 合作：Oracle 应用与数据进 ChatGPT，并推出 Security Mesh 等

OpenAI 10 月 27 日宣布深化与 Oracle 的企业合作：Oracle 应用与数据将进入 ChatGPT，同时推出 AI Workspace、AI Security Mesh、SMB Bundle 与 App Composer 等产品线。

2026-10-28 OpenAI

OpenAI 官方稿称，双方正把 Oracle 应用与数据接入 ChatGPT，并用 OpenAI 模型与产品为 Oracle 侧新产品赋能。目标表述是「面向智能体的企业环境」：员工在统一入口描述任务、检索信息、在组织权限与审批范围内完成业务流程。Oracle 披露内部已有约 13 万活跃 ChatGPT 用户、逾 9.5 万活跃 Codex 用户；招聘团队用 ChatGPT Work 做市场调研，准备时间从两到四天压到约十五到二十分钟。

产品侧要点：Oracle 在开发 Oracle AI Workspace，把财务、采购、规划等应用接到 ChatGPT；Oracle AI Security Mesh 计划用 OpenAI 网络安全模型帮客户发现并修复应用与基础设施漏洞，由 Oracle 管理测试基础设施；SMB Bundle 把 ChatGPT Business、Codex 与 Oracle 应用及周期性 OCI 额度打包给中小企业；App Composer 则让团队用 Codex 等工具建应用、接到已批准的数据与工作流，由 Oracle 在 OCI 上托管部署。美国客户还可通过 Oracle Marketplace 用既有采购流程与合格 Universal Credits 购买 API、Codex 与 ChatGPT Work。

本窗定位：今晨不回炒 GPT-6.1 Terra 与科学合作稿；本条是企业分发与工作流入口。公开云 IaaS 容量本身不单开「云厂商」栏目，但 OpenAI 产品进 Oracle 应用栈属于模型公司分发新闻，归 OpenAI 栏。

边界：AI Workspace 等仍偏「正在开发 / 宣布」口径，不以已全面商用写作。安全测试强调「经授权范围」，勿写成可对任意生产系统无差别扫描。

交叉核对

  • 多方一致：OpenAI 官方确认 Oracle 应用进 ChatGPT、Workspace/Security Mesh/SMB/App Composer 与 Marketplace 采购路径。
  • 分歧/二手：内部用户数与招聘效率为 Oracle 自报，未见独立审计。
  • 待确认：Workspace 全面可用时间表、Security Mesh 与 OpenAI 网络安全模型的具体版本绑定。
