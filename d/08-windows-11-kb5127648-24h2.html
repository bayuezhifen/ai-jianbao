操作系统与桌面

Windows 11 十月补丁日：KB5127648 上线，24H2 消费版官方表记已结束更新

微软 Learn 发布健康页显示 2026-10-13 推送 KB5127648（24H2 至 26100.9711 等）；同一表格将 24H2 的 Home/Pro 等消费渠道标为 End of updates，企业等渠道仍支持到 2027-10-12。

2026-10-14 操作系统与桌面

微软 Windows 11 发布信息页将 2026-10 B 更新记为 2026-10-13：KB5127648 覆盖 26H2 / 25H2 / 24H2（对应最新构建 26300.9711、26200.9711、26100.9711），26H1 则走 KB5127646。Neowin 同日整理的修复项包括：安全累积、Secure Boot 证书继续铺开、多用户环境 Explorer 黑屏、Always On VPN 卡住、部分游戏鼠标顿挫、Windows Hello 指纹冷启动等。

生命周期表是本条另一重点：24H2 在「Home, Pro, Pro Education, Pro for Workstations」列已写 End of updates；「Enterprise, Education…」列仍为 2027-10-12。也就是说，消费版用户若还停在 24H2，十月这次很可能是官方渠道最后一轮常规月更，应规划迁到 25H2 或 26H2。企业 LTSC 24H2 仍按长期渠道维护，勿与消费版混读。

Ubuntu 26.10 仍约在 10/15 正式窗口，本条不抢发发行说明。晨报只收已挂出的微软官方表与已报道的 KB 号。

操作建议：先查 winver 与 Windows Update 历史是否已是 26100.9711；消费版 24H2 尽快评估功能更新路径，企业版按变更窗口测试后部署。

交叉核对

  • 一手：learn.microsoft.com Windows 11 release information（EOL 表 + KB 行）。
  • 二手：Neowin 列 KB5127648/7646 修复摘要。
  • 边界：消费版 EOL ≠ 企业版同步 EOL。
