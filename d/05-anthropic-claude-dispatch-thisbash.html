The Register 独家：Claude Dispatch「ThisBash」设计缺陷可致远程命令执行

Forever Security 披露 Claude Dispatch 设计缺陷「ThisBash」：恶意浏览器扩展可经已登录的 claude.ai 网页会话指挥 Claude Desktop 执行命令；Anthropic 5 月已知、拟退役 Dispatch 未兑现，未发 CVE/赏金；Cowork/Remote Control 据称同类风险。

2026-11-06 Claude / Anthropic

The Register 2026 年 11 月 5 日独家报道：Forever Security 研究员 Gal Weizman 发现并命名为「ThisBash」的问题——Claude Dispatch 的界面与 API 可从普通已登录的 claude.ai 网页会话触达，因而能控制该域的浏览器扩展，便可冒充合法 Dispatch 用户，向本机甚至同账号下另一台机器上的 Claude Desktop 下发任务并执行命令，无需浏览器漏洞，用户交互也很少。

攻击链大致是：扩展在 claude.ai 注册主世界脚本 → 打开 Dispatch 弹窗 → 用环境 Cookie 拉取 cowork-dispatch 会话 → 连续「强提示」并自动点 Allow，直至安装恶意 npm 包或跑本地命令。前提是扩展能碰 claude.ai，且用户已登录网页端与开启 Dispatch 的 Desktop；Weizman 称 Cowork 网页会话与 Claude Code Remote Control 共享会话后，对 Dispatch 的依赖更低。

披露时间线：Anthropic 5 月承认有效漏洞但以「已在跟踪的重复项」关闭，未付赏金、未发 CVE，并称拟于 10 月底退役 Dispatch；截至 10 月 30 日支持页仍写 Dispatch 对部分 Pro/Max/Ultra 限量可用、老用户可继续用。Weizman 认为即便退役 Dispatch，跨端共享会话的设计仍把浏览器边界打穿，风险迁到 Cowork 等功能。

企业侧更刺眼的是「个人账号登录公司电脑」：Dispatch 可跨机，个人浏览器会话可能指挥公司 Desktop。报道援引 Forever 客户样本，个人 Claude 账号在企业环境占比约 18%–71%。OpenAI Codex 等「网页看不到桌面会话」的设计被用作对照。本条按独家调查报道处理，Anthropic 未回应 The Register 置评。
